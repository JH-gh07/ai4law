# AI4Law 知识库调研包（P0，v1）

更新日期：2026-03-29
适用范围：`中国大陆 -> 境外` 数据跨境合规（初赛优先）

## 1. 目录结构

- `raw/`：原始网页快照（不改写，保留证据）
- `index/sources.csv`：法规/指南/问答/政策页面总索引
- `index/practice_cases.csv`：公开实践案例与可验证样例索引
- `normalized/`：结构化中间层（条文级对象）
- `evaluation/`：如何用案例做可行性与有效性验证

## 2. 当前完成情况（P0）

- 已补齐中国路径核心规范与指南（含 2024 规定、2025 政策问答、2025 申报指南第三版）
- 已补齐基础法层（网安法、数安法、个保法、网数条例）
- 已收集官方公开实践案例与统计口径（北京公开平台 + CAC 口径）
- 已形成“案例如何用于评测”的执行方法

## 3. 使用原则

- 权威优先：`CAC / gov.cn / 地方政府公开平台` 为主
- 证据可回溯：索引必须包含原始 URL 和本地快照路径
- 可直接工程化：每条数据预留 `jurisdiction/path/doc_type/status` 标签
- 冲突处理：同主题冲突信息按 `官方法规 > 官方问答 > 地方实践 > 第三方解读`
