# 中国数据出境路径Reference库清单

中国数据出境路径Reference库清单
一、 法律（全国人大及其常委会制定） 
	•	《中华人民共和国网络安全法》（2017年施行）
	•	《中华人民共和国数据安全法》（2021年施行）
	•	《中华人民共和国个人信息保护法》（2021年施行）
	•	《中华人民共和国民法典》（第四编第六章“隐私权和个人信息保护”）
	•	《中华人民共和国刑法》（第二百五十三条之一“侵犯公民个人信息罪”）
二、 行政法规（国务院制定） 
	•	《网络数据安全管理条例》（2025年1月1日施行）
三、 部门规章及规范性文件（国家网信办、国家数据局、市场监管总局等制定） 
（一） 数据出境专项管理
	•	《数据出境安全评估办法》（国家互联网信息办公室令第11号，2022年施行）
	•	《个人信息出境标准合同办法》（国家互联网信息办公室令第13号，2023年施行）
	•	《促进和规范数据跨境流动规定》（国家互联网信息办公室令第16号，2024年施行）
	•	《个人信息出境认证办法》（国家互联网信息办公室、国家市场监督管理总局令，2026年1月1日施行）
（二） 配套申报与备案指南
	•	《数据出境安全评估申报指南（第一版）》（国家互联网信息办公室，2022年发布）
	•	《数据出境安全评估申报指南（第二版）》（国家互联网信息办公室，2024年发布）
	•	《个人信息出境标准合同备案指南（第一版）》（国家互联网信息办公室，2023年发布）
	•	《个人信息出境标准合同备案指南（第二版）》（国家互联网信息办公室，2024年发布）
	•	《数据出境安全评估申报书（模板）》（附于申报指南）
	•	《数据出境风险自评估报告（模板）》（附于申报指南）
	•	《经办人授权委托书（模板）》（附于申报指南）
	•	《个人信息保护影响评估报告（模板）（出境版）》（附于标准合同备案指南）
	•	《承诺书（模板）》（附于标准合同备案指南）
（三） 个人信息保护与合规审计
	•	《个人信息保护合规审计管理办法》（国家互联网信息办公室，2025年施行）
	•	《关于开展个人信息保护负责人信息报送工作的公告》（国家互联网信息办公室，2025年发布）
（四） 行业及领域数据安全管理
	•	《中国人民银行业务领域数据安全管理办法》（中国人民银行，2025年施行）
	•	《自然资源领域数据安全管理办法》（自然资源部，2026年施行）
	•	《工业和信息化领域数据安全管理办法（试行）》（工业和信息化部）
	•	《汽车数据安全管理若干规定（试行）》（国家互联网信息办公室等五部门，2021年施行）
四、 国家标准（GB/T，推荐性） 
（一） 基础通用标准
	•	《信息安全技术 个人信息安全规范》（GB/T 35273-2020）
	•	《信息安全技术 个人信息安全影响评估指南》（GB/T 39335-2020）
	•	《信息安全技术 数据安全技术 数据分类分级规则》（GB/T 43697-2024）
	•	《信息安全技术 个人信息去标识化效果分级评估规范》（GB/T 42460-2023）
	•	《信息安全技术 个人信息处理中告知和同意的实施指南》（GB/T 42574-2023）
（二） 数据跨境专项标准
	•	《数据安全技术 个人信息跨境处理活动安全认证要求》（GB/T 46068-2025，2026年3月1日实施）
	•	《网络安全标准实践指南—个人信息跨境处理活动安全认证规范》（TC260-PG-20222A，已由GB/T 46068-2025替代升级）
（三） 其他相关安全标准
	•	《信息安全技术 大数据服务安全能力要求》（GB/T 35274-2017）
	•	《信息安全技术 大数据安全管理指南》（GB/T 37973-2019）
	•	《信息安全技术 重要数据识别指南》（在研/征求意见中）
五、 行业标准及重要数据识别指南（各部委发布） 
（一） 工业领域
	•	《工业领域重要数据识别指南》（YD/T 4981-2024，通信行业标准）
	•	《工业企业数据安全防护要求》（YD/T 4982-2024）
	•	《工业领域数据安全风险评估规范》（YD/T 6415-2025）
	•	《工业数据分类分级指南（试行）》（工业和信息化部，2020年发布）
（二） 电信领域
	•	《电信领域重要数据识别指南》（工业和信息化部发布）
（三） 车联网领域
	•	《车联网平台重要数据识别指南》（YD/T 6617-2025，通信行业标准）
（四） 自然资源领域
	•	《地理信息数据分类分级工作指南（试行）》（自然资源部发布）
（五） 金融领域
	•	《银行保险机构数据安全管理办法》（国家金融监督管理总局，2024年施行）
	•	《促进和规范金融业数据跨境流动合规指南》（中国人民银行等六部门，2025年发布）
	•	《保险资产管理行业数据分类分级指南》（团体标准，2026年施行）
（六） 统计领域
	•	《统计数据安全管理办法》（国家统计局发布）
六、 地方性法规、自贸区数据出境负面清单及管理办法 
（一） 省级数据条例（含数据跨境条款）
	•	《江苏省数据条例》（2025年）
	•	《浙江省数字经济促进条例》（含数据要素相关条款）
	•	《上海市数据条例》（含数据要素相关条款）
	•	《深圳经济特区数字经济产业促进条例》
	•	《海南自由贸易港国际数据中心发展规定》（2024年）
	•	《珠海经济特区数据资源开发利用条例》（2025年）
（二） 自贸区数据出境负面清单及管理办法
	•	《中国（北京）自由贸易试验区、国家服务业扩大开放综合示范区数据出境负面清单管理办法（试行）》
	•	《中国（北京）自由贸易试验区、国家服务业扩大开放综合示范区数据出境管理清单（负面清单）（2025版）》（覆盖汽车、医药、零售、民航、人工智能等9大领域）
	•	《中国（上海）自由贸易试验区及临港新片区、国家服务业扩大开放综合试点地区（上海）数据出境负面清单管理办法（试行）》
	•	《中国（上海）自由贸易试验区及临港新片区、国家服务业扩大开放综合试点地区（上海）数据出境管理清单（负面清单）（2025版）》（覆盖金融、航运、商贸、气象等领域）
	•	《中国（上海）自由贸易试验区及临港新片区数据出境负面清单实施指南（试行）》
	•	《天津市自由贸易试验区数据出境负面清单》
	•	《海南省自由贸易港数据出境负面清单（2024版）》（覆盖深海、航天、种业、旅游、免税零售等领域）
	•	其他自贸试验区（如广东、福建、重庆、广西等）制定的数据出境负面清单（具体名称以各地发布为准）。
七、 其他相关重要文件 
	•	《个人信息保护认证实施规则》（国家市场监督管理总局、国家互联网信息办公室公告）
	•	《常见类型移动互联网应用程序必要个人信息范围规定》（国家互联网信息办公室等四部门，2021年发布）
	•	《App违法违规收集使用个人信息行为认定方法》（国家互联网信息办公室等四部门，2019年发布）
	•	《儿童个人信息网络保护规定》（国家互联网信息办公室，2019年施行）
	•	《互联网信息服务算法推荐管理规定》（国家互联网信息办公室，2022年施行）
	•	《互联网信息服务深度合成管理规定》（国家互联网信息办公室，2023年施行）
	•	《网络数据安全管理条例（征求意见稿）》（已由正式条例替代，列于第6项）
	•	《数据出境安全评估申报指南（第一版）》及其所有附件（承诺书、申报表、自评估报告模板等）
	•	《个人信息出境标准合同备案指南（第一版、第二版）》及其所有附件（承诺书、标准合同范本、PIPIA报告模板等）
	•	各省（自治区、直辖市）网信办发布的数据出境安全评估申报工作指引（如《海南省数据出境安全评估申报工作指引（第三版）》）。
