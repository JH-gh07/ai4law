## 2. Demo 演示路径（推荐）

### 路径 A：合规路径诊断 -> 报告生成

1. 进入首页并选择 `中国大陆 -> 境外` 场景。
2. 进入“合规路径诊断”，回答 5 个关键问题。
3. 查看路径判定结论与法规依据，下载诊断报告。
4. 一键跳转到“安全评估”或“SCC”模块，自动预填上下文。
5. 上传材料，触发报告生成任务，查看进度。
6. 在线预览章节、引用链、风险分级与门控标记。
7. 下载 docx / ZIP 交付物。

### 路径 B：文档智能审查

1. 上传标准合同或隐私政策。
2. 系统执行条款切分、分类、逐条审查。
3. 在双栏界面查看“原文定位 + 审查意见”。
4. 按 HIGH/MEDIUM/LOW 风险筛选问题。
5. 导出《合规审查报告》。
