# 《"数规通"项目使用说明书》

## 1. 产品概述

### 1.1 产品定位

数规通（AI4Law）是一款面向企业数据跨境合规场景的 AI 辅助工具，帮助法务合规团队快速判断合规路径、自动生成合规文书草案、智能审查合规文件。产品适用于处理中国大陆、欧盟、美国等主要法域的数据跨境合规事务。

**重要声明：** 本产品为合规辅助工具，所有输出结果仅供参考，不构成正式法律意见。使用前须经具备相应资质的律师或法务人员复核确认。

### 1.2 适用对象

本产品主要面向以下三类用户：

**企业法务/合规团队：** 需要处理日常数据跨境合规申报、文件审查和制度建设的企业内部人员，是本产品的主要使用群体。

**律所合规团队：** 为客户提供数据跨境合规服务的律师和顾问，借助本产品扩大服务产能、提升交付效率，同时保证专业质量。

**企业数据保护官（DPO）：** 负责企业数据合规整体管理，需要快速了解合规状态和风险敞口的管理人员，使用本产品获取可解释的合规路径分析和风险分级结果。

使用本产品需要具备基本的数据合规知识（了解数据出境合规的基本概念即可，无需深入研读法律条文）。

### 1.3 使用前提与注意事项

使用前请了解以下重要事项：

① 本产品所有输出均为**草案**，须经专业法律人员复核后方可用于正式申报或外部交付；

② 输入材料中含有企业敏感信息时，请确认已获得相应数据使用授权，并在上传前完成脱敏处理；

③ 产品标注**"需人工复核"**的内容节点为高风险或低置信度内容，请重点关注并由专业人员人工确认，不得直接采信；

④ 当前版本主要覆盖中国大陆数据出境场景（P0），EU/US 法域功能正在持续完善中。

## 2. 使用流程总览

### 2.1 产品总体使用流程

完整使用流程分为三大步骤，步骤间通过系统上下文自动衔接：

**第一步：路径诊断**（必做）→ 回答 5 个问题 → 获取合规路径建议和诊断报告

**第二步：报告生成**（核心功能）→ 进入对应报告模块 → 填写表单 + 上传材料 → 系统生成报告草案 → 法务人员复核后形成正式文件

**第三步：文件审查**（可选，与第二步并行或独立使用）→ 上传相关合同或政策文件 → 获取条款级审查意见 → 下载审查报告 → 整改后可再次上传进行第二轮审查

### 2.2 路径诊断使用流程

**第一步：** 访问产品首页，在场景面板中选择适用的出境方向（如"中国大陆→境外"）；

**第二步：** 点击"合规路径诊断"，进入诊断问题界面；

**第三步：** 依次回答 5 个标准化问题，每个问题附有字段说明（鼠标悬停或点击"?"图标可查看）；

**第四步：** 点击"提交"，系统即时返回路径判断结论（包含推荐路径、法规依据、置信度），耗时 <2 秒；

**第五步：** 查看并下载《合规路径诊断报告》（PDF 和 docx 双格式，约 2–3 页）；

**第六步（可选）：** 点击结论页底部的"前往[路径名]模块"，系统携带上下文自动跳转，企业基本信息自动预填至目标模块的表单。

### 2.3 文书生成使用流程

以安全评估报告为例：

**第一步：** 进入安全评估模块（从路径诊断跳转，或直接在导航栏选择）；

**第二步：** 填写企业基本信息表单（标 * 为必填字段，从路径诊断跳转的用户部分字段已自动预填）；

**第三步：** 上传相关材料——数据清单（Excel 格式）和企业数据处理协议（Word 或 PDF 格式），可选上传补充附件；

**第四步：** 点击"生成报告"，系统提交异步任务并显示进度条。此时可离开页面，任务在后台执行，完成后前端自动更新状态；

**第五步：** 任务完成后，在线预览报告章节，重点查看：引用链标注（点击可展开查看法规原文）、HIGH 风险节点（红色高亮）、人工复核提示（黄色警示图标）；

**第六步：** 下载报告文件，可选 docx（可编辑）、PDF（留档）或 ZIP（含全部格式）；

**第七步：** 法务人员对报告中高风险标注和人工复核标记节点逐一审查确认，修改完善后，将文件名中的"草案"字样改为"定稿"版本，用于正式申报。

### 2.4 文件审查使用流程

**第一步：** 进入文件审查模块；

**第二步：** 上传待审查文件（支持 Word .docx 和 PDF 格式，建议不超过 50MB）；

**第三步：** 选择审查类型（标准合同审查 / 隐私政策审查 / 数据处理协议审查）和适用法律（中国大陆 / 欧盟 GDPR / 美国 CPRA）；

**第四步：** 系统自动切分条款并执行审查（约 60–180 秒，视文件长度而定），可在页面实时查看进度；

**第五步：** 在审查结果界面查看各条款的问题清单，可按 HIGH / MEDIUM / LOW 风险等级筛选；

**第六步：** 逐条查看原文定位（含页码和段落位置）+ 审查意见 + 法规依据 + 修改建议（含参考改写示例）；

**第七步：** 下载《合规审查报告》（docx/PDF）和结构化问题清单（Excel 格式，含整改状态追踪列）；

**第八步（可选）：** 根据审查建议修改文件后重新上传，进行第二轮审查。系统仅重审内容已修改的条款，保持审查口径稳定。

## 3. 功能操作说明

### 3.1 功能入口说明

产品主要功能入口分三个层级：

**顶部导航栏：** 提供管辖区域选择（中国大陆 / EU / US）、"报告中心"（历史任务列表和已生成报告）、"知识库"（可查阅收录的法规列表和条文）三个全局入口。

**场景面板：** 进入特定法域场景后（如"中国大陆→境外"），显示该场景下支持的所有功能模块——合规路径诊断、各类报告生成模块（安全评估、SCC、PIPIA 等）、文件审查。

**任务工作台：** 每个功能模块的操作界面，采用双栏布局——左侧为输入区（表单填写 + 文件上传），右侧为结果区（章节预览、引用链展示、风险标注）。

### 3.2 输入信息填写说明

填写关键输入字段时请注意以下要点：

**企业类型（CIIO 判断）：** 关键信息基础设施运营者（CIIO）一般为电信、能源、金融、交通、水利、医疗、教育等关键行业的运营商。如不确定，建议选择"非 CIIO"（系统将选取更保守的合规路径），并向主管机关或专业律师进一步确认。

**数据量规模：** 按历史峰值或预计最大规模填写，建议选择偏保守（较高档位）的区间，以确保合规路径判断充分覆盖实际情况。

**数据处理目的：** 尽量如实描述具体业务场景（如"集团内部员工 HR 管理"或"为境外用户提供服务"），该字段内容将直接影响报告中"出境必要性分析"章节的内容质量。

**上传文件格式建议：** Word 格式（.docx）的文档解析效果优于 PDF；文件大小建议不超过 50MB；若 PDF 为扫描版（非文字型），系统可能无法正常解析，请转换为文字型 PDF 或 Word 格式后再上传。

### 3.3 输出结果查看说明

查看报告结果时，请重点关注以下标注元素：

**引用链（法规依据）：** 在报告预览界面，每条关键法律结论后附有引用链标注，点击可展开查看完整法规原文（含法律名称、条文编号、引用原文）。引用链是验证结论可追溯性的重要依据。

**风险标注：**
- **HIGH 风险**（红色标记）：存在明确合规缺陷或高度不确定性，须优先处理，不得直接使用于正式申报；
- **MEDIUM 风险**（橙色标记）：存在潜在合规隐患，建议整改后再提交；
- **LOW 风险**（绿色标记）：形式性问题或说明性内容，可酌情处理。

**人工复核标记：** 黄色警示图标（⚠）标注的内容表示系统置信度不足（如输入材料信息缺失、法规依据不充分或存在专业争议），务必经专业人员人工确认，不得直接采信。

**版本说明：** 下载的报告文件名包含"草案"字样。经法务人员复核修改后，请在定稿时更新文件名和文档内的草案声明段落。

## 4. 典型使用案例

### 4.1 案例输入内容

**案例背景：** 某互联网科技公司（非 CIIO）计划将国内用户数据传输至香港子公司进行集中运营管理，法务团队使用"数规通"完成从路径诊断到合规文书准备的完整工作流。

**路径诊断输入：**

| 问题 | 用户回答 |
|------|---------|
| 企业类型 | 非 CIIO（普通企业） |
| 数据类型 | 个人信息，含少量敏感个人信息 |
| 普通个人信息规模 | 50 万–100 万条 |
| 敏感个人信息规模 | 1 万条以下（约 5000 条） |
| 出境目的 | 集团内部管理（传输至境外子公司） |

**文书生成补充输入（SCC 模块）：**

- 企业基本信息表单（企业名称、数据处理目的、境外接收方信息，部分字段已从路径诊断自动预填）
- 数据清单.xlsx：包含用户账户信息（80 万条）、交易记录（含 5000 条支付信息）的数据类型、数量、处理目的和接收方说明，已脱敏
- 数据处理协议.docx：约 8 页，含数据处理范围、安全措施、数据主体权利等条款，已脱敏

### 4.2 系统处理流程

**Step 1：路径诊断（耗时 <2 秒）**

规则引擎按五层规则顺序判断：非 CIIO → 非重要数据 → 普通个人信息未达 100 万阈值 → 敏感个人信息未达 1 万阈值 → 出境目的为集团内部管理。

判断结论：推荐**标准合同备案**路径，置信度 HIGH，附 3 条法规依据（《个人信息保护法》第 38 条、《个人信息出境标准合同办法》第 3 条、第 5 条）。

用户下载《合规路径诊断报告》存档后，点击"前往 SCC 模块"，系统携带上下文自动跳转，企业类型、数据规模等字段已自动预填。

**Step 2：文书生成（耗时约 60 秒）**

用户补充上传数据清单和数据处理协议后，点击"生成报告"，系统以异步任务执行五步流水线：

- 材料理解（约 10 秒）：LLM 解析上传文件，抽取结构化企业画像（CompanyProfile JSON）；
- 法规检索（约 8 秒）：RAG 引擎检索本地 1011 条法规索引，为各章节召回 Top-8 相关条文；
- 逐章节生成（约 25 秒）：LLM 逐章生成报告内容，6 个章节全部通过 JSON Schema 首次校验；
- 一致性校验（约 5 秒）：检测到 1 处数据量前后表述差异，自动标注；
- 渲染输出（约 2 秒）：生成 docx + PDF + ZIP 三种格式文件。

用户在进度界面实时查看当前执行步骤，任务完成后自动跳转至报告预览页。

**Step 3：结果复核**

法务人员在报告预览页重点关注 2 处 HIGH 风险标注和 3 处人工复核标记，根据系统提供的修改建议逐一修改完善，形成正式申报文件。

### 4.3 最终输出结果

本案例完整操作总耗时约 5–10 分钟（含表单填写和文件上传准备时间），系统生成耗时约 1 分钟。

**输出文件清单：**

| 文件 | 格式 | 用途 |
|------|------|------|
| 数规通\_合规路径诊断报告\_[日期].pdf | PDF | 存档路径判断结论及法规依据 |
| [企业简称]\_SCC合规审查报告\_草案\_[日期].docx | Word | 法务人员复核修改，用于备案准备 |
| [企业简称]\_SCC合规审查报告\_草案\_[日期].pdf | PDF | 留档备份 |
| [企业简称]\_SCC合规审查报告\_草案\_[日期].zip | ZIP | 完整输出包（含全部格式） |

与传统人工起草方式对比，路径判断从 20–30 分钟压缩至 <2 秒，报告草案生成从 3–5 个工作日压缩至约 1 分钟。

## 5. 输出物说明

### 5.1 路径诊断结果说明

《合规路径诊断报告》内容结构如下：

① **执行摘要：** 推荐路径（标准合同备案 / 安全评估 / 个人信息出境认证）+ 置信度（HIGH/MEDIUM/LOW）+ 关键法规依据（1–3 条）；
② **诊断问题与回答记录：** 5 个问题的用户输入完整记录，便于后续复核和存档；
③ **详细判断分析：** 逐层法规依据说明（每条判断规则对应的法规条文和判断逻辑）；
④ **注意事项与不确定性说明：** 列出需要额外关注的前提条件和不确定因素；
⑤ **建议下一步行动：** 推荐进入的下一个功能模块及其说明。

输出格式：PDF 和 docx 双格式，约 2–3 页。

### 5.2 合规文书输出说明

**文件格式：** docx（可编辑，含样式）、PDF（不可编辑，用于留档）、ZIP（包含 docx + PDF + Markdown 三格式）。

**内容规范：** 章节标题和格式符合监管申报规范（参照国家互联网信息办公室官方申报模板）；所有关键法律结论附完整引用链；HIGH 风险节点红色高亮显示；人工复核标记用黄色警示图标标注；文档末尾包含"草案声明"和"复核清单"（列出所有需人工确认节点汇总）。

### 5.3 审查报告输出说明

《合规审查报告》内容结构如下：

① **执行摘要：** HIGH 风险问题数量、总体合规评估；
② **完整问题清单：** 按风险等级（HIGH → MEDIUM → LOW）排序，每条含原文引用 + 问题描述 + 风险依据 + 修改建议；
③ **整改建议总结：** 按优先级排列的整改任务清单，区分"必须整改"和"建议优化"；
④ **附录：** 审查使用的法规清单（法律名称 + 版本 + 来源）；
⑤ **声明：** 本报告为 AI 辅助审查结果，仅供参考，不构成法律意见，须经专业法律人员复核后使用。

输出格式：docx 和 PDF 双格式；同步提供结构化问题清单 Excel（便于整改管理，含状态追踪列）。

## 6. 常见问题与使用建议

### 6.1 常见输入问题

**Q1：不知道企业是否属于 CIIO 怎么办？**

CIIO 主要包括电信、能源、金融、交通、水利、医疗、教育等关键行业的基础设施运营商，具体认定须参考《关键信息基础设施安全保护条例》。如不确定，建议选择"非 CIIO"（系统将选取更保守的合规路径），并向主管机关或专业律师进一步确认。

**Q2：企业数据量不确定，应该如何填写？**

建议按历史峰值或预计最大规模填写，选择偏保守（较高档位）的区间，以确保合规路径判断充分覆盖实际情况。若后续数据量发生重大变化，建议重新执行路径诊断。

### 6.2 结果理解方式

**Q3：报告中 HIGH 风险标注的内容是否表示企业违规？**

HIGH 风险标注不直接表示企业当前违规，而是系统识别到该节点存在较高的合规风险或不确定性，需要法务人员重点关注和专业判断。具体是否构成违规以及如何应对，须经具备专业资质的律师或法务人员审核确认。

**Q4：报告中"需人工复核"标记的内容意味着什么？**

该标记表示系统检索到的法规依据不足，或该问题具有较高的专业复杂度，系统无法给出高置信度结论，必须由专业人员人工判断，不得直接引用于正式文件。

### 6.3 人工复核建议

以下场景**必须经过专业律师或法务人员复核**后方可使用系统输出：

① 所有 HIGH 风险标注的内容；
② 所有"需人工复核"标记（⚠）的内容；
③ 最终用于监管申报、备案或正式提交监管机构的合规文书；
④ 涉及重要数据或大规模个人信息（百万量级以上）的高风险场景；
⑤ 首次使用本产品处理某类新业务场景时，建议进行一次全面复核，建立企业内部使用基准。
