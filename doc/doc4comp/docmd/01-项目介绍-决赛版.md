# 《"数规通"项目介绍（决赛版）》

## 1. 项目基础信息

### 1.1 项目名称与项目定位

本项目中文名为**"数规通"**，取"数据合规、一通百通"之意，英文名为 **AI4Law**，参赛赛题方向为 D06"法律 AI 应用创新与实践"。

产品定位为**企业数据跨境合规 AI 工具**，核心价值主张为：将企业非结构化业务材料自动转化为可用于监管申报与内部决策的标准化合规资产。在数据出境合规监管持续收紧、企业合规成本居高不下的背景下，"数规通"通过 AI 技术将传统需要数天至数周的人工合规流程压缩为分钟级的草案生成，同时以结构化中间态、引用链、风险门控等机制确保输出内容的规范性和可审计性，满足法律场景对 AI 工具的可信度要求。

## 2. 项目需求分析

### 2.1 行业背景与现实需求

近年来，中国数据跨境合规立法进程显著加快。2021 年《数据安全法》与《个人信息保护法》相继落地，确立了数据分类分级保护与个人信息跨境传输的基本制度框架；2022 年《数据出境安全评估办法》正式施行，明确了安全评估申报的适用场景与流程；2023 年《个人信息出境标准合同办法》实施，进一步规范了标准合同备案路径。随着监管窗口全面打开，大量出海企业和跨国公司面临前所未有的合规压力。

然而，企业在落地执行层面面临四大现实痛点：

**痛点一：合规路径判断复杂。** 数据出境需根据企业性质（是否为关键信息基础设施运营者）、数据类型（重要数据/个人信息/敏感个人信息）、数量规模等多维条件判断应走"安全评估申报""标准合同备案"还是"个人信息出境认证"路径，法务人员需深入研读多部法规方可准确判断，非专业人员几乎无从入手。

**痛点二：合规文书产出成本高。** 《数据出境风险自评估报告》《个人信息保护影响评估报告（PIPIA）》等文书结构复杂、字数量大，传统上完全依赖法律专业人员人工撰写，周期通常为数天至数周，且重复性极高，难以规模化。

**痛点三：合规审查不可规模化。** 企业在跨境数据传输前需对相关合同、隐私政策、数据处理协议进行逐条合规审查，工作量与文件数量线性增长，一致性难以保证，亦难以应对法规更新后的批量重审需求。

**痛点四：可追溯与可审计要求高。** 法律场景对 AI 工具的信任前提是"结论可追溯"——每条风险判断背后必须有明确的法规依据，每个高风险节点必须有人工复核记录，否则企业无法将 AI 输出用于正式申报或内部治理。

### 2.2 目标用户分析

本项目面向三类核心目标用户，各有不同的使用场景与核心诉求：

**出海/跨国企业法务合规团队（主要用户）：** 日常需处理大量跨境数据合规申报、内部文件审查和制度建设任务。痛点集中在效率低下与成本高企，核心诉求是：以最低人工投入完成合格的合规文书草案，并能快速识别已有文件中的合规风险点。

**律所及合规服务机构（专业用户）：** 为企业客户提供数据跨境合规咨询与文书服务。业务量增长但专业人力有限，核心诉求是：用 AI 工具扩大服务产能、提升交付效率，同时保证专业质量（可追溯、可复核）。

**企业数据保护官（DPO）及数据负责人（决策参考用户）：** 负责企业数据合规整体管理，需要快速了解合规路径、评估风险敞口、向管理层汇报合规进展。核心诉求是：可解释的合规路径分析和可视化的风险分级结果，而非难以消化的法规条文堆砌。

### 2.3 现有方案不足与项目切入点

当前市场上的主要解决方案各有明显短板：

**传统人工方式：** 完全依赖法律专业人员手工处理，效率低、周期长、成本高，输出质量高度依赖个人专业水平，难以标准化和规模化。

**通用法律 AI 问答工具（如 ChatGPT 类）：** 可提供法规咨询与解读，但无法直接输出符合申报格式要求的标准化文书，也无法完成结构化的文件审查；且 LLM 训练数据的时效性问题导致引用法规存在出错风险，法律场景难以接受。

**垂直合规 SaaS 平台（如合同管理系统）：** 功能局限于合同存储和流程管理，缺乏路径诊断能力和合规文书生成能力，无法覆盖"从诊断到交付"的完整合规流程。

本项目的切入点在于填补上述方案之间的空白：采用"规则引擎（确定性路径诊断）+ LLM（内容生成与审查）+ RAG（法规检索）+ JSON Schema（输出约束）"的组合方案，打通"路径诊断 → 文书生成 → 文件审查"完整闭环，输出可直接交付使用的标准化合规资产，同时通过引用链与风险门控机制满足法律场景对 AI 工具的可信度要求。

## 3. 项目总体方案

### 3.1 总体设计目标

本项目围绕三大核心目标进行设计：

**效率目标：** 将"周级人工流程"压缩为"分钟级草案生成"。路径诊断 <2 秒即时返回结论；合规报告草案生成约 30-120 秒完成；文件审查约 60-180 秒产出条款级问题清单。

**质量目标：** 以结构化输出（JSON Schema 约束）和引用链（每条结论附法规依据）保证输出的规范性与可解释性，满足法律场景对输出内容"可追溯、可审计"的基本要求。

**安全目标：** 通过风险分级（HIGH/MEDIUM/LOW）与强制门控（高风险或低置信度内容自动标记需人工复核）保障系统的法律场景安全边界，确保 AI 不会产出具有明确误导性的法律结论。

### 3.2 业务闭环与核心思路

"数规通"的业务闭环以企业数据跨境合规的完整生命周期为主线设计：

1. **路径诊断：** 用户回答 5 个结构化问题，系统通过规则引擎即时判断应走"安全评估/标准合同备案/个人信息出境认证"哪条路径，输出路径诊断报告，并携带企业信息上下文跳转至对应功能模块。
2. **文书生成：** 用户在对应模块提交表单与附件，系统通过五步 AI 流水线（材料理解 → 法规检索 → 逐章节生成 → 一致性校验 → 渲染输出）自动生成合规文书草案，含引用链和风险标注。
3. **文件审查：** 用户上传已有合同或政策文件，系统逐条切分、分类、审查，输出条款级问题清单与修改建议，支持多轮"审查→整改→再审查"迭代。
4. **人工复核：** 法务/律师对系统标注的高风险节点和人工复核标记逐一审查确认，形成可用于正式申报的定稿文件。

各环节通过任务上下文（`task_id` + `context_json`）在系统内部传递信息，支持模块间无缝跳转，构成可追溯的完整操作链路。

### 3.3 项目核心优势与特色

与同类工具相比，"数规通"的核心差异化优势体现在四个方面：

**规则引擎诊断：** 路径判断采用前端确定性状态机，不依赖 LLM 推理，相同输入永远产生相同输出，判断延迟 <2 秒，判断依据严格可追溯至具体法规条文。

**结构化中间态：** LLM 不直接生成文档文字，而是先生成满足 JSON Schema 的结构化对象，程序化校验通过后再由 Python 渲染层转换为文档格式。这一设计将"格式合规"与"内容生成"解耦，确保每份报告的结构、引用格式、风险标注均符合预定规范。

**可追溯引用链：** 每条关键法律结论必须附至少 1 条具体法规引用（含法律名称、条文编号、引用原文），系统拒绝产出无依据的法律判断，支持逐条可审计。

**风险门控机制：** HIGH/MEDIUM/LOW 三级风险标注 + 人工复核强制标记，高风险或低置信度内容在前端界面高亮显示，引导法务人员重点审查，守住法律场景安全底线。

## 4. 项目关键功能

### 4.1 智能路径诊断

路径诊断功能通过 5 个核心问题（企业类型、数据类型、数量规模、出境目的、接收方情况）的规则状态机，判定企业在"中国大陆→境外"场景下应走安全评估申报、标准合同备案还是个人信息出境认证路径。

功能的关键设计特点：一是**前端确定性实现**，判断逻辑以规则树形式在应用层执行，不经过 LLM，零网络延迟、零不确定性；二是**结论法规依据可追溯**，判断结论附具体法规条文（如《数据出境安全评估办法》第 4 条），用户可验证判断逻辑；三是**上下文携带跳转**，诊断完成后一键跳转至对应报告生成模块，企业画像信息自动预填，避免重复输入。

输出物为《合规路径诊断报告》，提供 PDF 和 docx 双格式，包含推荐路径、判断依据、注意事项及建议下一步行动。

### 4.2 合规文书智能生成

文书生成功能支持 11 类合规报告的自动生成，覆盖三大法域的主要合规路径：

- **中国大陆：** 数据出境风险自评估报告（安全评估路径）、个人信息保护影响评估报告 PIPIA（认证/SCC 路径）、数据流转风险评估报告（14117 标准）；
- **欧盟：** 标准合同条款合规审查报告（SCC）、约束性公司规则审查报告（BCR）、数据保护影响评估草案（DPIA）、传输影响评估报告（TIA）；
- **美国：** CPRA/CCPA 合规全景报告。

生成流程采用五步 AI 流水线：材料理解（LLM 抽取企业画像）→ 法规检索（RAG 混合检索 1011 条条文）→ 逐章节生成（每章经 JSON Schema 校验）→ 一致性校验（跨章节矛盾检测）→ 渲染输出（docx/PDF/HTML/ZIP）。所有报告均包含完整引用链和 HIGH/MEDIUM/LOW 三级风险标注，高风险及低置信度节点强制标注人工复核提示。

### 4.3 合规文件智能审查

文件审查功能对上传的合同、隐私政策、数据处理协议等法律文件执行条款级合规审查，支持 Word 和 PDF 格式。

审查流程分四步执行：条款切分（按语义边界将文件拆分为独立条款单元）→ 条款分类（识别每条条款属于数据主体权利、跨境传输要求、数据安全措施等哪类合规要求）→ 逐条审查（与对应法规要求比对，识别缺失要素、表述不清、与法规冲突等问题）→ 聚合输出（按 HIGH/MEDIUM/LOW 风险排序，生成综合审查报告）。

每条审查结论包含：条款定位（原文引用 + 文档位置）、问题类型（缺失/表述不清/冲突/符合）、风险等级、法规依据（条文编号）、修改建议（含参考改写示例）。系统支持多轮迭代审查，每轮仅重审内容发生变化的条款，保持审查口径稳定。

### 4.4 用户交互与结果反馈闭环

产品前端采用 React 构建的双栏工作台界面：左侧为输入区（表单填写与文件上传），右侧为结果区（章节预览、引用链展示、风险标注）。报告生成等耗时任务采用异步执行机制，用户提交后可离开页面，系统在后台完成处理，任务完成后前端实时更新进度状态。

结果展示层面，引用链以悬浮标注形式展示（点击可查看法规原文）；HIGH 风险节点以红色高亮标记，人工复核提示以黄色警示图标呈现，引导法务人员快速定位需重点审查的内容。用户可按 HIGH/MEDIUM/LOW 风险筛选问题清单，一键下载 docx、PDF 或 ZIP 格式的交付物。

## 5. 项目应用场景

### 5.1 企业数据出境合规判断场景

**典型场景：** 某互联网科技公司（非 CIIO）计划将国内约 80 万条用户账户及交易数据传输至香港子公司用于集中运营管理，法务团队需确定合规路径并完成申报准备。

**操作流程：** 进入"中国大陆→境外"场景面板 → 启动路径诊断，依次填写企业类型（非 CIIO）、数据类型（个人信息，含少量敏感信息）、数量规模（普通 50-100 万/敏感 <1 万）、出境目的（集团内部管理）、接收方（境外子公司）→ 系统即时判断推荐路径（标准合同备案）并附法规依据（《个人信息出境标准合同办法》第 3 条）→ 下载诊断报告存档 → 一键跳转至 SCC 模块准备合规文书。

全过程耗时 <5 分钟，企业法务人员无需深入研读法规即可获得确定性的路径建议和可追溯的法规依据。

### 5.2 合规文书准备与生成场景

**典型场景：** 同一企业确定标准合同备案路径后，需准备《个人信息出境标准合同》相关合规文书。

**操作流程：** 进入 SCC 模块（路径诊断上下文自动预填企业基本信息）→ 补充填写必要字段，上传数据清单（Excel）和数据处理协议（Word）→ 点击"生成报告"，系统以异步任务方式执行五步流水线，进度实时展示 → 约 45-90 秒完成，在线预览生成的报告草案（查看引用链和风险标注，重点关注人工复核标记节点）→ 下载 docx 草案，法务人员对标注节点逐一复核修改后，作为正式申报材料提交。

传统方式需 3-5 天人工起草，系统将草案生成时间压缩至约 1-2 分钟（不含上传准备），法务人员聚焦在高价值的复核工作而非重复性的撰写劳动。

### 5.3 合规文件审查与整改场景

**典型场景：** 某企业在跨境数据传输前需审查现有《数据处理协议（DPA）》，确认是否符合《个人信息出境标准合同》要求。

**操作流程：** 进入文档审查模块，上传 DPA 文件（Word/PDF）→ 系统执行条款切分（约 38 条）、分类、逐条审查，约 90 秒完成 → 查看按风险等级排序的问题清单（如 HIGH 风险问题：缺少接收方所在国保护水平评估段落）→ 合规团队按 HIGH→MEDIUM→LOW 优先级逐条处理，参考系统提供的修改建议改写条款 → 上传修订版文件进行二次审查，系统仅重审已修改条款，确认问题是否已修复，直至主要风险点清零。

系统将 2-4 小时的人工逐条审查压缩至 90 秒初审，整改闭环通过多轮迭代机制全程可追踪。

## 6. 项目应用价值

### 6.1 创新性

**技术创新：** 率先将"规则引擎（确定性路径诊断）+ LLM（生成与审查）+ RAG（法规检索）+ JSON Schema（输出约束）"组合为面向法律合规场景的四位一体架构。规则引擎负责不容出错的判断逻辑，LLM 负责可灵活生成的内容创作，RAG 保障法规依据的准确性，JSON Schema 保障输出的结构规范性，四者各司其职、相互补位。

**产品创新：** 首次将"路径诊断 → 文书生成 → 文件审查"三个传统上相互割裂的合规工作环节以统一产品形态打通，形成端到端合规资产生成能力，上下文在各环节间自动流转。

**可信 AI 设计创新：** 引用链 + 风险门控 + 人工复核强制标记机制是专为法律场景设计的可信 AI 实践。系统不试图替代法律专业判断，而是以可追溯、可解释、可审计的方式辅助法务人员提升工作效率，在 AI 能力与法律场景安全要求之间找到了可落地的平衡点。

### 6.2 实用性

**覆盖度广：** 11 类报告覆盖中国大陆、EU、US 三大法域的主要数据跨境合规路径，适用企业无需针对不同法域寻找不同工具。

**输出可直接使用：** 生成的报告草案格式参照官方申报指南规范设计，法务人员复核后可直接用于监管申报或内部治理，无需大幅改写。

**效率提升可量化：** 路径诊断从人工 20-30 分钟压缩至 <2 秒；报告生成从人工 3-5 天压缩至约 1-2 分钟草案输出；文件审查从人工 2-4 小时压缩至约 90 秒初审。

**质量保障体系完整：** 三层自动化评测（L1/L2/L3）+ Golden Set 回归测试，保障系统能力在版本迭代中稳定，有明确的质量可见性。

### 6.3 推广可行性

**技术层面：** 前后端分离架构、容器化部署，支持快速上线与弹性扩展；API 接口标准化，支持后续以 SaaS 或私有化部署方式对外提供服务；技术栈成熟（FastAPI + React），具备持续迭代能力。

**市场层面：** 数据跨境合规需求随《数据安全法》《个人信息保护法》等立法持续落地而刚性增长，出海企业、跨国公司、律所、合规服务机构均为潜在用户，市场规模可观且需求明确。

**运营层面：** 产品"即开即用"，无需复杂配置或专业培训即可上手；核心功能以模板化方式沉淀合规知识，后续可通过订阅制（报告生成次数）、API 接入（B2B 集成）、企业私有化部署等多种商业化路径变现，商业模式清晰可行。
