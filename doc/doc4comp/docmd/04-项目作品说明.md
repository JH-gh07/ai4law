# 《"数规通"项目作品说明》

## 1. 项目作品概述

### 1.1 作品形态说明

"数规通"（AI4Law）是一款 Web 应用形态的企业数据跨境合规 AI 工具，具备两套前端界面：主交互界面基于 React 18 + TypeScript 构建，提供完整的产品功能交互，包括场景面板导航、双栏工作台（左侧输入/右侧结果）、异步任务进度追踪和报告在线预览；辅助仪表盘基于 Streamlit 构建，面向开发调试场景提供数据概览与模块测试能力。

应用采用前后端分离架构，前端通过 RESTful API（`/api/v1`）与后端通信，后端使用 FastAPI（Python）提供服务，AI 推理层由腾讯混元 LLM、自建 RAG 引擎和腾讯元器工作流编排平台协作构成。

可演示的核心功能模块包括：合规路径诊断（规则引擎，<2 秒响应）、11 类合规文书生成（含引用链与风险标注）、文件智能审查（条款级，支持 Word/PDF）、AI 合规助手（对话式咨询）。

## 2. 作品功能展示

### 2.1 路径诊断功能展示

路径诊断模块通过五个标准化问题的规则状态机，即时判定企业数据出境的合规路径，全程不经 LLM 推理，结论严格可追溯至具体法规条文。

**演示要点：**

1. 进入"中国大陆→境外"场景面板，点击"合规路径诊断"；
2. 依次填写五个问题（建议使用标准演示输入：非 CIIO 企业，普通个人信息 50–100 万条，敏感个人信息不足 1 万条，出境目的为集团内部 CRM 管理）；
3. 提交后系统即时返回路径判断结论（推荐标准合同备案）及三条法规依据（《个人信息保护法》第 38 条、《个人信息出境标准合同办法》第 3 条、第 5 条）；
4. 下载《合规路径诊断报告》PDF，展示报告结构（推荐路径 + 判断依据 + 注意事项 + 建议下一步行动）；
5. 点击"前往 SCC 模块"，展示上下文自动携带、企业信息预填效果。

### 2.2 文书生成功能展示

文书生成模块以五步 AI 流水线自动生成合规报告草案，支持 11 类报告，全程 JSON Schema 约束，强制引用链覆盖，高风险节点程序化标记。

**演示要点（以 SCC 审查报告为例）：**

1. 从路径诊断跳转至 SCC 模块（或直接从导航进入），确认企业基本信息预填情况；
2. 上传样例数据清单（Excel）和数据处理协议（Word），点击"生成报告"；
3. 展示任务提交后的异步进度追踪界面，可看到当前执行步骤依次推进：材料理解 → 法规检索 → 逐章节生成 → 一致性校验 → 渲染输出；
4. 任务完成后，在线预览报告章节，重点展示：章节正文 + 悬浮引用链标注（点击可查看法规原文）+ HIGH/MEDIUM/LOW 风险标注 + 人工复核警示图标；
5. 下载 docx 文件，展示文档格式规范性（章节结构符合官方申报模板样式，含草案声明与复核清单）。

### 2.3 文件审查功能展示

文件审查模块对上传的法律文件执行条款级合规审查，支持 Word 和 PDF 格式，输出可按风险等级筛选的问题清单与修改建议。

**演示要点：**

1. 进入文件审查模块，上传脱敏的样例《数据处理协议（DPA）》（Word 格式，约 12 页）；
2. 选择审查类型（数据处理协议审查）和适用法律（中国大陆《个人信息出境标准合同》要求）；
3. 展示系统条款切分结果（约 38 条条款独立显示，含原文和文档位置信息）；
4. 展示双栏审查结果界面：左侧显示原文定位，右侧显示审查意见 + 风险等级 + 法规依据 + 修改建议（含参考改写示例）；
5. 演示按 HIGH / MEDIUM / LOW 风险筛选功能，展示高风险问题（如：跨境传输条款缺少接收方所在国保护水平评估）；
6. 下载《合规审查报告》，展示格式（执行摘要 + 完整问题清单 + 整改优先级建议）。

### 3.1 视频内容结构

演示视频建议时长 4–8 分钟，分四段组织：

**开场（约 30 秒）：** 以"数据跨境合规监管收紧、企业合规成本居高不下"为背景引入，一句话点明产品定位——将传统数天的人工合规流程压缩为分钟级草案生成。

**核心功能演示（约 3–5 分钟）：**
- 路径诊断完整流程（约 1 分钟）：从填写问题到获取结论，展示规则引擎判断速度与法规依据展示；
- 报告生成完整流程（约 2 分钟）：展示表单填写、文件上传、异步进度追踪、报告预览（重点：引用链 + 风险标注 + 人工复核标记）、文件下载全过程；
- 文件审查完整流程（约 1 分钟）：展示上传、条款切分、双栏审查结果、高风险问题定位与修改建议。

**技术亮点说明（约 1–2 分钟）：** 简要介绍产品三大核心差异化特性——规则引擎确定性路径判断（零 LLM 不确定性）、JSON Schema 中间态约束（格式与内容解耦）、引用链 + 风险门控 + 人工复核机制（法律场景可信 AI 实践）。

**结果展示（约 40–60 秒）：** 展示输出文档样例内页（体现格式规范性），以量化数据总结产品效率价值（诊断 <2 秒、报告生成 1–2 分钟、审查 90 秒）。

### 3.2 核心展示重点

视频中必须清晰展示以下内容，作为产品核心竞争力的视觉证明：

## 4. 典型演示案例

### 4.1 案例背景与输入内容

**案例：某出海科技企业数据出境合规全流程**

某互联网科技公司（非 CIIO）计划将国内用户数据传输至香港子公司进行集中运营管理。数据情况：普通个人信息约 80 万条（用户账户、交易记录），敏感个人信息约 5000 条（支付信息）。

系统输入如下：

| 诊断问题 | 用户回答 |
|---------|---------|
| 企业类型 | 非 CIIO（普通企业） |
| 数据类型 | 个人信息，含少量敏感个人信息 |
| 普通个人信息规模 | 50 万–100 万条 |
| 敏感个人信息规模 | 1 万条以下 |
| 出境目的 | 集团内部管理（境外子公司） |

### 4.2 系统处理过程

**Step 1：路径诊断（<2 秒）**

规则引擎按优先级顺序执行判断：非 CIIO → 非重要数据 → 普通个人信息 50–100 万（未达 100 万阈值）→ 敏感个人信息 5000 条（未达 1 万阈值）→ 出境目的为集团内部管理。综合判断推荐标准合同备案路径，置信度 HIGH，附引用《个人信息保护法》第 38 条、《个人信息出境标准合同办法》第 3 条第 2 款、第 5 条。

**Step 2：切换至 SCC 模块**

用户点击"前往 SCC 模块"，系统携带路径诊断上下文自动预填企业基本信息（企业类型、数据规模、出境目的、接收方情况），用户补充上传数据清单（Excel）和数据处理协议（Word）。

**Step 3：文书生成（约 45–90 秒异步任务）**

系统依次执行：材料理解（约 10 秒，抽取 CompanyProfile JSON）→ 法规检索（约 8 秒，召回 Top-N 条文）→ 逐章节生成（约 20 秒，每章经 JSON Schema 校验）→ 一致性校验（约 5 秒，跨章节矛盾检测）→ 渲染输出（约 2 秒，生成 docx + PDF + ZIP）。

**Step 4：人工复核**

法务人员在线预览报告，重点审查 HIGH 风险标注节点（如"境外接收方所在国保护水平评估"段落）和人工复核标记处，对标注内容逐一确认修改后形成正式申报材料。

### 4.3 最终输出结果

输出文件：`[企业简称]_SCC合规审查报告_草案_[日期].docx`（同步生成 PDF 和 ZIP 包）

报告主要内容包括：
- **执行摘要：** 确认标准合同备案路径，列出 3 处高风险关注点；
- **数据出境必要性分析：** 结合 CompanyProfile 分析业务必要性，引用《个人信息保护法》第 39 条最小必要原则；
- **境外接收方评估：** 对香港子公司的数据保护能力评级（含 MEDIUM 风险标注及人工复核标记）；
- **合同条款建议：** 针对标准合同各核心条款的合规性审查，HIGH 风险节点高亮标注含具体修改建议；
- **综合风险评估：** 总体风险等级 MEDIUM，整改优先项 2 条，无需整改项若干。

## 5. 作品完成度说明

### 5.1 当前已实现能力

已完成并可演示的功能如下：

- **合规路径诊断：** 支持中国大陆主要路径判断（安全评估/标准合同备案/个人信息出境认证），规则引擎实现，响应 <2 秒；
- **11 类合规报告生成：** 安全评估报告、SCC 审查报告、PIPIA、BCR 审查报告、DPIA 草案、TIA 报告、14117 数据流转风险评估、CPRA 合规全景报告等，覆盖中国大陆、EU、US 三大法域；
- **文件智能审查：** 支持 Word/PDF 上传，条款级审查，输出 HIGH/MEDIUM/LOW 三级风险问题清单及修改建议，支持多轮迭代审查；
- **AI 合规助手：** 对话形式的合规咨询，基于 RAG 知识库作答，回答附法规引用；
- **知识库：** 收录 15 部核心法规，共 1011 条条文（384 维向量索引），覆盖中国大陆、EU、US 三大法域，附 7 个实践案例；
- **多格式输出：** docx（可编辑，含官方模板样式）/ PDF / HTML / ZIP 四种格式，文件名按规范命名。

### 5.2 系统稳定性说明

系统经过三层自动化评测体系验证：L1 检索层（RAG 相关度评分达标率）、L2 抽取层（Pydantic Schema 校验通过率）、L3 生成层（引用链覆盖率、风险字段完整率）。Golden Set 回归测试在基线数据集上通过，无能力退化。高风险/低置信度内容均有程序化门控保护，不会产出具有明确误导性的法律结论。

### 5.3 后续优化计划

后续计划在三个方向持续优化：

**RAG 质量提升：** 当前使用词汇匹配结合向量检索的混合策略，计划升级为语义嵌入模型（如 BGE-M3），提升跨语言和语义相似检索精度，进一步降低补充检索触发频率。

**路径覆盖扩展：** 当前 P0 重点为中国大陆出境场景，后续扩展 EU→CN、US→CN 等跨境传入场景的合规路径判断，支持更多出境目的地组合。

**产品化打磨：** 优化前端交互体验，增加历史报告管理、任务模板复用、企业画像持久化等功能，降低重复操作成本；完善多租户支持，为 SaaS 化部署做好架构准备。
