# 3.1 SCC审查

## 模块目标
对欧盟 SCC 文本进行条款级合规审查，输出结构化风险报告。

## 知识库要求

### 法规主信源
- GDPR Chapter V
- EU Standard Contractual Clauses 官方文本
- 欧盟委员会 Q&A 与配套说明

### 补充信源
- EDPB 解释性指南
- 实务案例与律所解读

### 模板资产
- SCC 审查报告模板

## 输入规范

### 结构化字段
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| review_scope | string | 是 | 审查范围 |
| data_flow_context | string | 是 | 数据流背景 |
| stance | enum(exporter/importer) | 否 | 审查立场 |

### 附件
| 附件 | 格式 | 必填 |
|---|---|---|
| SCC 文本（英文） | doc/docx/pdf | 是 |
| 补充附件 | docx/pdf | 否 |

## 输出规范
| 文件 | 命名规则 | 格式 |
|---|---|---|
| SCC合规审查报告 | `[企业简称]_SCC_合规审查报告_[日期].docx` | docx |
| 结构化问题清单 | `[企业简称]_SCC_问题清单_[日期].json` | json |

## 功能流程
1. 解析 SCC 结构。
2. 条款分类与风险标签。
3. 法规映射与冲突检测。
4. 输出报告与建议。

## 验收标准
- 覆盖核心条款（责任、通知、救济、转委托等）。
- 每条问题都可回溯到条款定位与法规依据。
