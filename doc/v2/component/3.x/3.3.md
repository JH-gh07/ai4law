# 3.3 DPIA草案生成

## 模块目标
根据业务场景自动生成 DPIA 草案（欧盟框架）。

## 知识库要求

### 法规主信源
- GDPR 第35条（DPIA）
- ICO DPIA 指南（brief + detailed）

### 补充信源
- EDPB 风险评估指导

### 模板资产
- `2.2 ICO_DPIA_Temple.docx`（模板）

## 输入规范

字段来源：`doc/v2/schemas/raw/module_input_fields.csv`（`module=3.3`，来源图 `3.3.png`）

### 附件
| 附件 | 格式 | 必填 |
|---|---|---|
| 业务流程图/数据流图 | pdf/png | 否 |
| 现有制度文件 | docx/pdf | 否 |

## 输出规范
| 文件 | 命名规则 | 格式 |
|---|---|---|
| DPIA 草案 | `[企业简称]_DPIA_草案_[日期].docx` | docx |

## 功能流程
1. 按 `3.3-1.1~3.3-7.2` 收集并校验输入。
2. 依据 `2.2 ICO_DPIA_Temple.docx` 映射章节。
3. 生成草案并输出。

## 验收标准
- 输出包含 DPIA 核心章节。
- 风险与措施一一对应。
