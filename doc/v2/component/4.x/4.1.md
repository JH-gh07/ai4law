# 4.1 对华数据流动合规（美国视角）

## 模块目标
评估“美国向中国（受关注国家）数据流动”场景合规风险，并输出执行建议。

## 知识库要求

### 法规主信源
- EO 14117 及实施细则（美国对敏感数据外流限制）
- 相关配套监管指引

### 补充信源
- 行业实践与机构解读

### 模板资产
- 对华数据流动合规报告模板（内部定义）

## 输入规范
字段来源：`doc/v2/schemas/raw/module_input_fields.csv`（`module=4.1`，来源图 `4.1.png`、`4.1.2.png`）

| 字段编码 | 字段名 | 输入方式 | 必填 | 说明 |
|---|---|---|---|---|
| 4.1-D1 | 出境数据清单 | Excel上传/在线编辑 | 是 | 表头含数据项名称、内容描述、业务场景、PI/SPI、出境必要性说明、示例 |
| 4.1-E1 | 外部实体清单 | 文件上传或表单逐条 | 是 | `csv/xlsx`；字段含实体全称、注册国家/地区、统一社会信用代码/税号、股权结构 |
| 4.1-E2 | 内部员工清单（如适用） | 文件上传 | 否 | `csv/xlsx`；字段含姓名、国籍、部门、岗位 |

| 附件 | 格式 | 必填 |
|---|---|---|
| 数据清单 | xlsx/csv | 是 |
| 实体清单 | xlsx/csv | 是 |
| 支撑材料 | docx/pdf | 否 |

## 输出规范
| 文件 | 命名规则 | 格式 |
|---|---|---|
| 对华数据流动合规报告 | `[企业简称]_对华数据流动合规报告_[日期].docx` | docx（建议） |
| 风险清单 | `[企业简称]_对华流动风险清单_[日期].xlsx` | xlsx（建议） |

说明：`4.1` 目前尚无“章节级输出映射图/官方输出模板结构”，该缺口已记录在 `doc/v2/schemas/raw/module_output_structure.csv`。

## 功能流程
1. 数据与实体清单解析。
2. 命中限制条件识别。
3. 风险评级与处置建议。
4. 生成报告与清单。

## 验收标准
- 能识别高风险数据类别与实体风险。
- 输出可执行整改建议。
