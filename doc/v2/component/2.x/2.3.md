# 2.3 认证/标准合同路径

## 模块目标
面向“个人信息出境认证/标准合同备案”场景，生成 PIPIA 报告草案。

## 知识库要求

### 法规主信源
- 《个人信息保护法》
- 《个人信息出境标准合同办法》
- 《个人信息出境标准合同备案指南（第二版）》
- 《个人信息出境认证办法》
- GB/T 46068《数据安全技术个人信息跨境处理活动安全认证要求》

### 补充信源
- 监管发布 FAQ、地方办理口径

### 模板资产
- `个人信息保护影响评估报告（模板）.docx`
- 标准合同条款模板

## 输入规范

字段来源：`doc/v2/schemas/raw/module_input_fields.csv`（`module=2.3`，来源图 `2.3.1.png`）

### 结构化输入模块
| 模块编码 | 输入项 | 输入方式 | 必填 | 对应报告章节 | 说明 |
|---|---|---|---|---|---|
| A | 处理者与出境活动基础信息 | Web表单（分步） | 是 | 一（1）1 / 一（2）1 / 一（3）3 | 企业信息、出境目的、合法性基础、必要性 |
| B | 出境个人信息清单 | Excel模板上传 | 是 | 一（1）3（3） | 字段含数据字段名、业务描述、数据类型、PI/SPI、所属场景 |
| C | 系统与存储信息 | Web表单+附件 | 是 | 一（1）3（4） | 境内外存储系统、数据中心位置、传输方式、架构图 |
| D | 境外接收方信息 | Web表单 | 是 | 一（二）境外接收方情况 | 接收方名称、国家、关系、处理目的与方式 |
| E | 法律文件 | 文件上传 | 是 | 评估依据 | 标准合同、处理协议、隐私政策 |
| F | 合规证据 | 文件上传+描述 | 是 | 一（1）4 / 一（3）2 | 单独同意证据、内部制度文件 |
| G | 自我评估与整改情况 | Web表单（引导式） | 建议 | 二 | 基于办法第五条的符合性评估与整改 |

### 附件清单
| 附件 | 格式 | 必填 | 说明 |
|---|---|---|---|
| 标准合同文本/认证材料 | docx/pdf | 是 | 主文档 |
| 场景说明材料 | docx/pdf | 否 | 补充背景 |
| 内部制度文件 | docx/pdf | 否 | 证明治理能力 |

## 输出规范

### 文件输出
| 文件 | 命名规则 | 格式 | 必出 |
|---|---|---|---|
| PIPIA 报告草案 | `[企业简称]_PIPIA_报告_草案_[日期].docx` | docx | 是 |

### 格式要求
- 版式对齐模板：四号仿宋/Times New Roman、行距 26 磅、固定页边距。

### 前端呈现
- 报告章节预览
- 核心风险摘要
- 可下载 docx

## 功能流程
1. 选择路径（认证/标准合同备案）。
2. 录入字段并上传材料。
3. 抽取 PIPIA 要素并补齐缺口。
4. 生成报告草案与建议。

## 落地任务
- 后端：路径路由、PIPIA 章节生成、样式渲染。
- 前端：路径切换、字段表单、预览下载。
- 数据：备案与认证条款映射。
- 测试：两路径输出差异、样式一致性。

## 验收标准
- 同一输入可稳定生成 docx。
- 输出包含 PIPIA 核心评估要素。
- 样式符合模板要求。
