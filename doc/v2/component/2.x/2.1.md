# 2.1 合规路径诊断

## 模块目标
通过 2 分钟问答，判定企业应走的数据出境路径（安全评估 / 标准合同备案 / 认证），并给出可追溯依据。

## 知识库要求

### 法规主信源
- 《中华人民共和国个人信息保护法》
- 《数据出境安全评估办法》
- 《个人信息出境标准合同办法》
- 《个人信息出境认证办法》与 GB/T 46068
- 官方来源优先：`cac.gov.cn`、`gov.cn`

### 补充信源
- 实务解读：`mp.weixin.qq.com`、律所文章（仅做解释，不替代法规）

### 模板资产
- 问答规则树（决策逻辑）
- 诊断报告模板（HTML/PDF）

## 输入规范

### 结构化字段
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| company_name | string | 是 | 企业简称/报告抬头 |
| q1_is_ciio | enum(yes/no) | 是 | 是否关基 |
| q2_has_important_data | enum(yes/no) | 是 | 是否含重要数据 |
| q3_pii_count | integer | 是 | 个人信息规模 |
| q4_spi_count | integer | 是 | 敏感个人信息规模 |
| q5_purpose | string | 是 | 出境目的 |

### 附件
- 无强制附件。

## 输出规范

### 文件输出
| 文件 | 命名规则 | 格式 | 必出 |
|---|---|---|---|
| 合规路径诊断报告 | `[企业简称]_合规路径诊断报告_[日期]` | pdf/html | 是 |

### 前端呈现
- 结论横幅（红/蓝/绿风险态）
- 命中规则链
- 法规依据列表（可展开）
- 后续行动 1~3 条
- “跳转下一模块”按钮（携带 session_id）

## 功能流程
1. 显示流程引导，开始问答。
2. 逐题作答并校验（未答不可下一步）。
3. 根据规则树判定路径。
4. 生成结论与依据。
5. 生成并下载报告。
6. 引导到 2.2 或 2.3。

## 落地任务
- 后端：规则树服务 + 诊断报告渲染 + 会话保存。
- 前端：动态问答页 + 结果页 + 跳转。
- 数据：法规依据映射表。
- 测试：阈值边界用例（CIIO、10万/100万/1万）。

## 验收标准
- 给定同一输入，判定稳定且可复现。
- 报告包含“摘要、路径、依据、行动”。
- 能成功跳转后续路径模块。
