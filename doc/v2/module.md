# AI4Law v2 模块清单（执行版）

主规范请看：`doc/v2/io.md`

## 中国大陆→境外

1. 2.1 合规路径诊断
- 目标：快速判定企业走“安全评估/标准合同备案/认证”路径。
- 输入：问答字段。
- 输出：诊断报告（pdf/html）。

2. 2.2 安全评估路径
- 目标：生成可提交前使用的风险自评估报告草案。
- 输入：结构化表单 + 申报材料附件。
- 输出：报告 docx + zip。

3. 2.3 认证/标准合同路径
- 目标：生成 PIPIA 报告草案。
- 输入：结构化字段（待补齐）。
- 输出：PIPIA docx。

4. 2.4 通用服务
- 目标：输出尽调/备忘录/TIA/整改建议。
- 输入：问题描述 + 业务材料。
- 输出：对应服务文档（建议 docx）。

5. 2.5 文档专项智能审查
- 目标：条款级识别风险并给修订建议。
- 输入：合同、隐私政策、内部制度等。
- 输出：审查报告 docx。
