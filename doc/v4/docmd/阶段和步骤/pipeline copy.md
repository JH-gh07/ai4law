整个产品的详细流程梳理：

---

## 产品定位

**产品名称**：基于AI大模型的数据跨境合规自动检测与风险评估工具

**服务对象**：有数据跨境业务的企业（跨国企业、出海企业）及其律师/律所

---

## 一、用户入口：首页

### 1.1 科普页面
向用户展示各主要法域的跨境数据传输框架：
- 中国框架（三条路径：安全评估、标准合同、个人信息保护认证）
- 欧盟框架（GDPR 跨境传输机制）
- 美国框架（CCPA/CPRA 等）

### 1.2 专项服务选择
用户选择自己的数据出境场景：
- 从中国大陆向境外传输数据
- 从欧盟（含英国）向境外传输数据
- 从美国向境外传输数据

---

## 二、以"中国大陆→境外"为核心的主流程

用户进入该场景后，看到五项专项服务模块：

```
①合规路径诊断  →  判断应走哪条路径
②安全评估路径  →  生成风险自评估报告
③认证/标准合同路径  →  生成个人信息保护影响评估报告
④通用服务  →  生成TIA、尽调报告、合规备忘录等
⑤文档智能审查  →  对现有法律文件进行合规性体检
```

---

## 三、模块①：合规路径诊断（智能问答）

**目的**：用2分钟问答，自动判断企业应走哪条合规路径。

**流程四步走：**

**状态0：入口**
用户点击"合规路径诊断"卡片进入全屏页面。

**状态1：开始**
展示流程说明，用户点击"开始诊断"。

**状态2：核心问题序列（动态问答，最多5题）**

| 题序 | 问题 | 判断逻辑 |
|---|---|---|
| 问题1 | 是否为关键信息基础设施运营者（CIIO）？ | 选"是" → 直接结论：必须申报安全评估 |
| 问题2 | 出境数据是否包含"重要数据"？ | 选"是" → 直接结论：必须申报安全评估 |
| 问题3 | 累计向境外提供的普通个人信息数量？ | 100万人以上 → 安全评估；10万~100万 → 标准合同/认证；10万以下 → 豁免路径 |
| 问题4 | 累计向境外提供的敏感个人信息数量？ | 1万人以上 → 安全评估；1万以下 → 标准合同/认证 |
| 问题5 | 出境的主要目的是什么？（动态出现） | 为后续报告预填合法性基础信息 |

**状态3：诊断结果**
- 醒目展示结论（红/蓝/绿图标+文字）
- 列出推理依据
- 提供后续行动指南
- 提供"生成详细诊断报告"按钮 → 输出 PDF/HTML 格式的《合规路径诊断报告》

**状态4：报告下载**
- 下载诊断报告
- 可一键跳转至对应的下一个功能模块（携带本次会话上下文）

---

## 四、模块②：安全评估路径

**触发条件**：企业属于 CIIO、出境重要数据、或普通个人信息超100万人/敏感个人信息超1万人。

**输入阶段**：通过表单填写+文件上传两种方式收集信息，内容对应网信办安全评估申报所需全部材料：
- 企业基本信息
- 数据出境相关合同
- 法定代表人/经办人身份证件
- 数据出境场景描述等

**输出阶段**：AI 自动生成：
- 核心交付物：`[企业简称]_数据出境风险自评估报告_草案_[日期].docx`（严格遵循网信办申报指南模板）
- 打包为 ZIP 文件，支持在线预览+一键下载

---

## 五、模块③：认证/标准合同路径

**触发条件**：非 CIIO，且普通个人信息在10万~100万之间，或敏感个人信息不满1万人。

**输入阶段**：收集企业信息、个人信息出境场景、境外接收方情况等。

**输出阶段**：AI 自动生成：
- 核心交付物：`[企业简称]_PIPIA_报告_草案_[日期].docx`（《个人信息保护影响评估报告》草案，严格遵循官方模板格式）

---

## 六、模块④：通用服务

生成以下衍生文件（不限于某一特定路径）：
- TIA（跨境传输风险评估）
- 尽调报告
- 合规备忘录
- 补充性防范措施建议
- 《风险与整改建议清单》（自动定位合规差距）

---

## 七、模块⑤：文档智能审查

**输入**：用户上传现有法律文件，包括：
- 《数据出境标准合同》《数据处理协议》
- 《云服务协议》中涉及数据处理的部分
- 《隐私政策》/《个人信息处理规则》
- 企业内部《数据安全管理制度》等

**输出**：《数据出境合同合规审查报告》（.docx），包含：
- 文件概要与审查依据
- 总体合规评级
- 逐条款问题清单（含：问题定位、原文引用、问题类型、风险分析、法规依据、修改建议）

---

## 八、知识库支撑体系

产品后台需要构建：
1. **信源库**：北大法宝、威科先行、Westlaw 等权威数据库 + 网信办官方文件
2. **自动更新功能**：主动搜索互联网可靠信源，屏蔽不可靠信源，及时同步至知识库
3. **覆盖范围**：以中国框架（三条路径所有规范+案例）为核心，兼顾韩国、欧盟（GDPR）、英国、美国、新加坡等法域

---

## 整体产品流程图（文字版）

```
首页（科普 + 场景选择）
    └── 选择"中国大陆→境外"
            ├── ①合规路径诊断
            │       └── 动态问答（5题）→ 诊断结论 → 诊断报告
            │               └── 一键跳转至②或③
            ├── ②安全评估路径（CIIO/重要数据/100万+个人信息）
            │       └── 信息输入 → AI生成《风险自评估报告草案》.docx
            ├── ③认证/标准合同路径（10万~100万个人信息）
            │       └── 信息输入 → AI生成《个人信息保护影响评估报告草案》.docx
            ├── ④通用服务
            │       └── 生成TIA / 尽调报告 / 合规备忘录 / 整改建议清单
            └── ⑤文档智能审查
                    └── 上传现有合同/隐私政策 → AI输出《合规审查报告》.docx
```

---

产品的核心价值链是：**用户描述业务场景 → AI判断合规路径 → AI生成可直接用于申报或内部决策的标准化合规文件**，将原本需要律师团队数周完成的工作大幅提效。
