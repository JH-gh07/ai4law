# 2.1 合规路径诊断：每个问题对应的路径结论

## 问题1：是否包含“重要数据”

**问题**：本次向境外提供的数据中，是否包含被相关部门或所在行业认定为“重要数据”的数据？

### 分支结论

- **选“是”**
  → **直接终止**
  → **路径结论：必须申报数据出境安全评估**。
- **选“否”**
  → 进入**问题2**。
- **选“不知道”**
  → **不产出结论**
  → 系统提示“重要数据”定义，并要求用户**返回本题重选**。

## 问题2：是否包含“个人信息”

**问题**：本次向境外提供的数据中，是否包含个人信息？

### 分支结论

- **选“否”**
  → **直接终止**
  → **路径结论：属于豁免情形，无需进行安全评估、订立标准合同或通过保护认证**。
- **选“是”**
  → 进入**问题3**。

## 问题3：是否属于法定豁免情形

**问题**：请判断本次个人信息出境是否属于以下任一法定豁免情形。
包括：

1. 为订立或履行个人作为一方当事人的合同所必需
2. 为实施跨境人力资源管理所必需
3. 紧急情况下为保护生命健康和财产安全所必需
4. 自当年1月1日起累计向境外提供的一般个人信息不足10万人
5. 位于自贸试验区且不涉及当地负面清单。

### 分支结论

- **选“是（命中任一豁免）”**
  → **直接终止**
  → **路径结论：属于豁免情形，无需进行安全评估、订立标准合同或通过保护认证**。
- **选“否（均不属于）”**
  → 进入**问题4**。

你指出的问题是对的：
**问题树只判断到了“大类路径”，但没有继续把“标准合同”和“认证”拆开。**

也就是说，这套规则树目前只能输出：

- 豁免
- 安全评估
- 标准合同 / 认证（二选一）

但**不能单独输出**：

- 一定走标准合同
- 一定走个人信息保护认证

原因也很直接：附件在 **10万–100万一般个人信息** 和 **不足1万敏感个人信息** 的场景下，只写了
**“应当订立个人信息出境标准合同或通过个人信息保护认证”**，没有进一步设计分流问题。
