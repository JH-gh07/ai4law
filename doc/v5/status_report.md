### 2.3 向量相似度实测（HashingEmbedder 核心问题）

| 词对 | 余弦相似度 | 说明 |
|------|------------|------|
| "标准合同" vs "SCC standard contractual clauses" | **0.0000** | 完全无重叠 token |
| "安全评估" vs "数据出境风险审查" | **0.0000** | 完全无重叠 token |
| "个人信息出境" vs "个人信息跨境传输" | 0.5634 | 共享"个人信息"字面重叠，非语义 |
| "个人信息出境" vs "个人信息出境" | 1.0000 | 自身对照 |

**根因**：HashingEmbedder 是基于字符 n-gram 的哈希向量，只能捕捉字面 token 重叠，完全没有语义理解。两个意思相同但用词不同的表达，向量相似度为 0。

### 2.5 得理法搜触发情况

实测三组"稀有查询"，得理法搜**从未被触发**：

| 查询 | 本地命中 | 得理触发 |
|------|----------|----------|
| 特定国家数据传输豁免 | 5 | ❌ 未触发 |
| 跨国公司内部数据共享BCR认证 | 5 | ❌ 未触发 |
| 数据主体权利请求响应时限 | 5 | ❌ 未触发 |

**根因**：触发条件是 `len(docs) < min_local(3)`，但哈希向量总能"凑"出 5 条结果（即使质量极差），所以得理法搜永远不会被触发。外部 API 形同虚设。

## 四、当前可用程度评估

| 场景 | 可用性 |
|------|--------|
| 精确关键词查询（如"标准合同备案"） | ✅ 可用，词汇检索兜底有效 |
| 同义词/近义词查询 | ❌ 不可用，召回结果随机 |
| 中英混合查询 | ❌ 不可用 |
| 欧盟/美国法域语义查询 | ⚠️ 部分可用，依赖法规名命中 |
| Off-topic 过滤 | ❌ 中文场景完全失效 |

**总体判断**：当前 RAG 对精确关键词命中有一定效果，靠的是词汇检索（lexical_score）而非向量相似度。向量检索部分实际上对中文语义几乎没有贡献。
