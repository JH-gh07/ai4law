# DataComply Flow Docs 页面建设说明（V1）

## 1. 页面定位
Docs 不是营销页，也不是任务执行页。它的定位是平台级“说明与指引中枢”：
- 对外：解释平台做什么、怎么用、适用边界是什么。
- 对内：统一模块口径、输入输出规范、流程标准和术语。
- 对执行：为用户从“看懂”过渡到“会做”提供可操作指南。

一句话定位：**Docs 是 DataComply Flow 的方法手册与使用中台**。

## 2. 与其他页面关系
### 2.1 与首页
- 首页负责价值表达与场景吸引（Why）。
- Docs 负责方法解释与操作说明（How）。
- 首页可引导“了解更多”进入 Docs。

### 2.2 与任务空间（Tasks）
- Tasks 负责项目管理与任务选择（What to run）。
- Docs 提供各任务模板说明、输入要求、完成标准（How to prepare）。

### 2.3 与工作台（Workspace）
- Workspace 负责执行、审阅、导出（Do）。
- Docs 负责执行前准备、执行中参考、执行后复核标准（Guide）。

### 2.4 与知识库中心（Evidence）
- Evidence 负责证据检索与法规引用（Source）。
- Docs 负责产品内方法与规则解释（Product Guide）。
- 两者互链：Docs 的法规说明区可跳 Evidence。

## 3. 用户进入 Docs 的核心诉求
用户主要要解决 5 类问题：
1. 平台能解决什么，不能解决什么。
2. 不同模块怎么选、怎么走完整流程。
3. 每个模块需要准备什么输入材料。
4. 输出报告怎么看、怎么用、如何复核。
5. 常见报错/权限/预览问题如何处理。

## 4. 页面承载内容范围
Docs 适合承载以下内容：
- 平台总览（目标、边界、适用法域）
- 快速开始（首次使用 5 步）
- 模块说明（Diagnosis / Assessment / Review / Report）
- 输入输出规范（字段、文件、结果）
- 流程说明（从建任务到导出交付）
- FAQ（账号、权限、文件预览、任务执行）
- 术语表（中英术语与统一定义）
- 版本更新（变更记录）

## 5. 页面结构（左目录 + 中正文）
### 5.1 布局目标
- 左侧目录：导航与定位。
- 中间正文：连续阅读与完整理解。
- 形成标准文档阅读体验，而非碎片卡片流。

### 5.2 左侧目录区
- 支持一级/二级目录。
- 点击目录项，正文锚点跳转。
- 正文滚动时目录同步高亮当前章节。
- 目录建议固定（sticky），正文独立滚动。

### 5.3 中间正文区
- 支持长文连续阅读。
- 标题层级清晰（H1/H2/H3）。
- 每节包含：结论、适用场景、操作步骤、注意事项。

## 7. 各分区内容模板
每个正文分区建议统一模板：
- 本节目标：这一节解决什么问题。
- 你会得到：读完后可完成什么动作。
- 关键说明：核心规则/概念。
- 操作步骤：按 1-2-3 执行。
- 常见误区：容易出错点。
- 相关章节：下一步该看哪里。

## 8. 文案风格规范
### 8.1 风格基调
- 专业：术语准确、边界清晰。
- 可读：短句优先，先结论后解释。
- 指导性：每节都能落到操作动作。

### 8.2 写法规则
- 标题用动作导向：如“如何选择合规路径”。
- 段首先给结论，再给理由。
- 列表化表达替代大段堆砌。
- 风险提示与免责声明单独成块。

### 8.3 禁止项
- 只讲概念不讲操作。
- 混用术语且无定义。
- 过度营销化表达。

## 9. Docs 首页屏文案建议
### 9.1 主标题
**DataComply Flow 文档中心**

### 9.2 副标题
为跨法域合规任务提供统一的使用说明、模块指南与输出标准，帮助你从“理解平台”快速进入“稳定执行”。

### 9.3 首屏快捷入口
- 5 分钟快速开始
- 模块说明总览
- 输入输出规范
- 常见问题

### 9.4 首屏提示文案
建议先阅读《快速开始》，再进入对应模块章节；执行中可随时回查输入要求与输出解释。

## 10. 验收标准（页面建设完成判定）
1. 目录支持一级/二级结构，点击可跳转。
2. 正文滚动时目录可同步高亮。
3. 页面具备长文可读性（不是卡片拼贴）。
4. 用户可在 3 次点击内找到任一核心模块说明。
5. FAQ 与术语表可直接支撑日常问题排查。
6. 文档内容可直接指导任务执行与结果复核。

## 11. 建设优先级建议
- P1：完成布局骨架（左目录 + 中正文 + 锚点高亮）。
- P1：完成“快速开始 + 模块说明 + FAQ”三大主内容。
- P2：补齐输入输出规范与术语表。
- P3：接入版本更新记录与搜索能力。
