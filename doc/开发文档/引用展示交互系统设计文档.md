# 引用展示交互系统设计文档

## 版本
- 日期: 2026-06-03
- 版本: v1.0

## 1. 设计目标

### 1.1 核心交互模型

引用展示系统采用**二层信息架构**：

```
悬浮 (hover) → 快速预览：判断引用是否可信、来自哪个层、治理状态
点击 (click) → 跳转原文：在知识库中查看引用的法条全文及上下文
```

Citation 不是自包含的元数据终点，而是**指向知识库原文的指针**。

### 1.2 适用范围

所有路径层和功能层都需要逐步支持引用展示：

| 模块 | 引用类型 | 说明 |
|------|----------|------|
| cn_assessment | 法规条文引用 | 安全评估报告中的法律依据 |
| pipia / dpia / tia / cpra | 法规条文引用 | 各路径评估报告 |
| review / scc / bcr | 法规 + 标准条款引用 | 条款级对比审查 |
| cn_diagnosis | 法规补证引用 | 路径判断的法律依据展示 |

## 2. 用户交互规格

### 2.1 行内引用标记

报告中法规引用以 `[n]` 上标形式出现：
- 蓝色可点击样式（区别于普通文本）
- 每个引用编号全局唯一（同一引用全文使用同一编号）
- 与 `citation_map.json` 中的 `footnote_map` 对应

### 2.2 Hover - CitationPopover 浮窗

触发方式：鼠标悬停在 `[n]` 上 200ms 后出现。

展示内容：
- **标题** + 条文号（如 `个人信息保护法 第39条`）
- **原文片段**（最多 120 字符，超出省略）
- **类型 badge**（法律条文 / 官方指南 / 模板要求 / 标准条款 / 案例参考 / 用户材料）
- **权威 badge**（高权威 / 中权威 / 参考）
- **治理状态指示**：
  - `✅ 可对外引用` — `external_report_allowed = true`
  - `⚠️ 仅供内部审查` — `external_report_allowed = false`
  - `🔴 禁止进入对外文书` — `can_enter_external_report = false`
  - `🟡 置信度不足 [待验证]` — 置信度低于阈值

### 2.3 Click - 知识库原文查看

触发方式：点击 `[n]` 上标或 popover 区域。

**方案 A — CitationArticleDrawer（侧边抽屉）**：
- 从屏幕右侧滑出，宽度约 520px
- 不打断报告阅读上下文
- 显示被引用条文的完整原文 + 上下文（前一条 / 后一条）
- 底部有"在官方来源查看"链接
- 适用于快速验证引用内容

**方案 B — LawViewerPage（独立页面）**：
- 跳转到 `/knowledge/laws/{source_id}?article={article_no}`
- 全屏浏览整部法规，当前条文高亮定位
- 支持条文间导航（上一条 / 下一条 / 返回目录）
- 显示完整法规元数据（发布机构、发布日期、生效日期、权威等级、约束力）
- 适用于深度阅读和法律研究

### 2.4 双方案协作关系

```
[悬浮] CitationPopover (始终存在)
  ├─ 点击 → 默认打开 ArticleDrawer (方案A)
  └─ Drawer 内 "在独立页面查看" 按钮 → 跳转 LawViewerPage (方案B)
```

## 3. 技术架构

### 3.1 数据流

```
citation_map.json (后端生成)
    ↓
GET /api/v1/citations/reports/{task_id}
    ↓
前端 CitationMarkdownRenderer
    ├─ 正则解析 markdown 文本中的 [n] 标记
    ├─ 匹配 footnote_map[n] → CitationDetail
    ├─ 渲染 CitationPopover (hover)
    └─ onClick → source_id + article_no
        ↓
GET /api/v1/knowledge/sources/{source_id}/articles/{article_no}
    ↓ (新 API)
返回: { title, article_no, article_content, prev/next context, source_url }
    ↓
前端 CitationArticleDrawer 或 LawViewerPage
```

### 3.2 组件树

```
AssessmentIntermediatesPanel (或其他模块报告面板)
  └── CitationMarkdownRenderer (NEW, 可复用)
        ├── 纯文本 span (非引用部分)
        ├── CitationPopover (引用部分, hover 浮窗)
        │     └── onClick →
        │           ├── CitationArticleDrawer (方案A, 侧边抽屉)
        │           │     └── "在独立页面查看" →
        │           └── LawViewerPage (方案B, 独立页面)
        └── CitationSourceCard (兼容保留, 当 KB 原文不可用时回退)
```

## 4. 后端 API 设计

### 4.1 新增端点

**`GET /api/v1/knowledge/sources/{source_id}/articles/{article_no}`**

请求参数：
- `source_id` (path): 来源标识，如 `CN-LAW-001`
- `article_no` (path): 条文号，如 `39`

响应 `ArticleDetailResponse`:
```json
{
  "source_id": "CN-LAW-001",
  "title": "中华人民共和国个人信息保护法",
  "article_no": "39",
  "article_content": "个人信息处理者向中华人民共和国境外提供个人信息的，应当向个人告知...",
  "prev_article_no": "38",
  "prev_article_content": "...",
  "next_article_no": "40",
  "next_article_content": "...",
  "source_url": "https://...",
  "authority_level": "high",
  "binding_force": "mandatory",
  "jurisdiction": "cn",
  "doc_type": "law"
}
```

### 4.2 修改端点

**`GET /api/v1/citations/reports/{task_id}`** — CitationDetailResponse 新增字段：
- `source_kind: str`
- `allowed_usage: list[str]`
- `can_enter_external_report: bool`
- `external_report_allowed: bool`
- `confidence_threshold: float`

## 5. 前端组件规格

### 5.1 CitationMarkdownRenderer (NEW)

**职责**：接收原始 markdown 文本，将 `[n]` 标记替换为可交互的 CitationPopover。

**Props**:
```typescript
interface CitationMarkdownRendererProps {
  markdown: string;
  taskId: string;
}
```

**行为**：
1. 挂载时调用 `fetchCitationMap(taskId)` 获取引用映射
2. 正则 `/\[(\d+)\]/g` 分割文本
3. 数字部分渲染 `<CitationPopover onClick={openDrawer} />`
4. 纯文本部分渲染 `<span>`

### 5.2 CitationArticleDrawer (NEW, 方案A)

**职责**：侧边抽屉展示知识库中的法条原文。

**Props**:
```typescript
interface CitationArticleDrawerProps {
  citation: CitationDetail;
  onClose: () => void;
  onViewFullLaw?: () => void;  // "在独立页面查看" 回调
}
```

**行为**：
1. 调用 `fetchArticleDetail(citation.source_id, citation.article_no)`
2. 渲染法规标题 + 元数据
3. 高亮当前条文
4. 显示前一条/后一条作为上下文
5. 底部 "在官方来源查看" 链接
6. "在独立页面查看" 按钮 → 跳转 LawViewerPage

### 5.3 LawViewerPage (NEW, 方案B)

**职责**：知识库法规全文浏览独立页面。

**路由**: `/knowledge/laws/:sourceId?article=39`

**行为**：
1. 根据 source_id 加载法规全文
2. 以文章形式展示所有条文
3. 当前条文（article_no 参数）高亮定位（scrollIntoView）
4. 目录导航（条文列表）
5. 显示完整法规元数据
6. 返回按钮

### 5.4 CitationPopover 改造

**现有关闭行为**: onClick → CitationSourceCard modal
**新行为**: onClick → CitationArticleDrawer 侧边抽屉

治理状态指示新增：
- 来源层 badge（L1 法规证据层 等）
- 外部报告权限状态
- 置信度 vs 阈值对比
