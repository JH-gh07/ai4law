一、后端三层

① 运行时事件层 — RunEventStream（扩展现有 TraceRecorder）
事件类型
status
thought
tool_start
tool_result
intermediate
warning / error
final
final_brief
事件流转
CPRAService.run()
  → stream.record("thought", ...)
    → TraceRecorder 写 JSON 文件
    → SSEManager 推前端
  → stream.record("tool_start", ...)
  → stream.record("intermediate", ...)
  → stream.record("final", ...)
  → stream.record("final_brief", ...)
传输
SSE 主通道
GET /task/{id}/stream
→ FastAPI StreamingResponse
→ text/event-stream

轮询兜底
GET /task/{id}/events?since={seq}
→ SSE 断连时降级
→ 1-2s interval

③ 最终摘要层 — 复用 TraceManifest.audit_summary() 思路

建议下一步 · 不暴露内部 trace

💭 Thought → 🔧 Tool start → ✅ Tool result

⚠️ Warning → 🏁 Final result

📝 结果简报 (Run Brief) — 新增

可打印/导出

三、数据流总览

CPRA Service → stream.record()

    ├─→ TraceRecorder → storage/traces/run_xxx/ （JSON 文件 · 审计）
    └─→ SSEManager → GET /task/{id}/stream → 前端 SSE
                                   └─→ fallback: GET /task/{id}/events?since={seq} (轮询)

前端消费

    ├─→ 对话 面板（现有）
    ├─→ 执行流 面板（新增 · 消费 SSE 事件）
    ├─→ 中间结果 面板（通用化现有）
    └─→ 结果简报 面板（新增 · 消费 final_brief 事件）
