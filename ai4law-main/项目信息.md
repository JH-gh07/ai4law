# 项目信息

本文档用于协助项目成员统一填写项目简介、开发信息、功能说明、技术方案与演示材料说明。  
内容综合参考了 `开发文档` 目录中的项目材料，并以当前仓库中的实际实现情况为准。

## 1. 项目基础信息

- 项目名称：数规通
- 英文名称：DataComply Flow
- 项目副标题：AI驱动的数据跨境合规诊断与文书智能生成平台
- 项目方向：法律科技 / 合规科技 / 智能法务
- 项目形态：Web 端智能合规工作台
- 项目定位：面向存在跨境数据流动需求的企业、法务与律师团队，提供“路径判断、材料准备、文书生成、文档审查、整改推进”一体化支持

## 2. 项目要解决的问题

### 2.1 合规路径判断难

企业在开展跨境数据业务时，往往难以快速判断自己应进入哪条合规路径，例如中国大陆安全评估、标准合同、认证路径，或欧盟 SCC、BCR、DPIA、TIA 等。  
传统方式依赖人工检索法规、比对案例和多轮沟通，效率低、稳定性弱、判断成本高。

### 2.2 材料准备成本高

无论是安全评估申报材料、个人信息保护影响评估报告，还是 DPIA、TIA、SCC 配套材料，都存在结构复杂、信息来源分散、协同角色多、返工频繁等问题。  
很多团队不是不会做，而是准备周期长、成本高、交付难以标准化。

### 2.3 文档审查难沉淀

企业已有的隐私政策、DPA、标准合同、SCC、BCR 等文件通常需要逐条审查。  
人工审查容易出现问题定位不清、依据不完整、意见不成体系、结果难复核等情况。

### 2.4 多法域协同复杂

中国大陆、欧盟、美国等法域在规则结构、文书要求和监管重点上差异明显。  
企业一旦涉及多地业务，就容易出现规则重复理解、材料重复准备、流程难以统一的问题。

## 3. 项目核心方案

项目采用“诊断 - 生成 - 审查 - 整改”的闭环思路，将复杂合规任务拆解为可执行、可预览、可交付的工作流。

### 3.1 智能诊断

通过结构化问答、规则判断和场景识别，快速输出：

- 适用路径
- 关键判断依据
- 风险提示
- 下一步建议动作

### 3.2 文书生成

结合用户填写信息、上传材料和模板要求，自动生成合规文书草案，包括但不限于：

- 数据出境安全评估报告草案
- 个人信息保护影响评估报告草案
- DPIA 草案
- TIA 草案
- CPRA 合规分析报告

### 3.3 文档审查

针对已有法律文本执行条款级或章节级分析，识别：

- 缺失条款
- 风险条款
- 适用依据
- 修订建议
- 优先级提示

### 3.4 统一交付与预览

系统支持在统一工作区内完成材料管理、模块运行、产物沉淀和内容预览，减少“先下载再打开”的割裂流程。

## 7. 项目亮点与差异化

### 7.1 聚焦高门槛场景

项目聚焦数据跨境合规这一高专业门槛场景，不是泛法律问答工具，也不是通用文本生成器，而是面向真实业务流程的合规工作平台。

### 7.2 打通业务闭环

系统不是只做某一个点状能力，而是围绕“判断 - 准备 - 生成 - 审查 - 整改”形成完整流程。

### 7.3 覆盖多法域

支持中国大陆、欧盟、美国典型场景，具备跨区域合规任务统一组织的基础能力。

### 7.4 兼顾专业性与产品化

项目既强调法律合规专业表达，也强调工作台、预览、文件管理、Copilot 协作等产品化体验，更接近真实 SaaS 工具而非一次性演示页面。

## 9. 典型使用场景

### 场景一：先判断该走哪条合规路径

用户通过诊断模块输入业务背景、数据类型、出境场景和接收方信息，系统输出推荐路径、依据说明和下一步动作建议。

### 场景二：准备正式申报或内部合规材料

用户通过结构化表单和附件上传输入信息，系统自动生成评估报告、影响评估草案或其他申报/合规文书草案。

### 场景三：审查现有合同或制度文件

用户上传隐私政策、DPA、标准合同、SCC、BCR 等文件，系统输出风险点、依据说明、修订建议及批注修订版产物。

### 场景四：在统一工作台完成交付复核

项目成员可在工作区直接管理输入输出、查看报告正文、切换预览内容，并结合 Copilot 进行补充问答与整理。

## 15. 开发部分可直接填写的项目信息

### 15.1 项目技术架构

- 前端：`React 18`、`TypeScript`、`Vite`、`React Router`、`Tailwind CSS`

- 运行形态：前后端分离，前端负责工作台交互与预览，后端提供模块化 API 与文档生成/审查服务

### 15.2 系统分层说明

- 展示层：首页、法域入口页、任务空间页、统一工作台、报告中心、证据中心、设置页
- 交互层：任务创建、模块运行、文件树联动、报告预览、Copilot 辅助问答、工作流步骤展示
- 服务层：诊断服务、报告生成服务、文档审查服务、知识检索服务、制品预览服务、系统设置服务
- 能力层：LLM 调用适配、RAG 检索、风险评分、文档解析、批注修订、任务状态管理
- 存储层：本地数据库、上传文件目录、输出报告目录、法规知识索引

### 15.3 当前已落地的核心功能模块

- 中国大陆路径诊断：输出合规路径、规则命中依据、后续动作建议，并支持生成诊断报告
- 数据出境安全评估报告生成：生成《数据出境风险自评估报告》草案，支持同步/异步任务
- PIPIA 生成：生成个人信息保护影响评估报告草案
- 欧盟 SCC 审查：生成合规审查报告，并支持批注修订版导出
- 欧盟 BCR 审查：输出结构化审查意见与报告草案
- 欧盟 DPIA 生成：根据问卷信息生成 DPIA 草案
- 欧盟 TIA 生成：根据接收方、国家与保障措施生成 TIA 草案
- 美国 EO 14117 场景分析：输出风险评估结论报告
- 美国 CPRA 合规分析：输出 CPRA 合规全景报告
- 通用文档审查与工作区交付：支持产物列表、正文预览、文件点击联动、证据/问题汇总与 Copilot 协作

### 15.4 前端实现信息

- 采用多页面工作台式产品结构，包含首页、法域中心、任务空间、工作区、报告中心、证据中心、设置中心
- 通过任务模板机制组织中国大陆、欧盟、美国不同法域与不同模块的工作流入口
- 工作区支持左侧资源面板、中部模块运行与报告页签、右侧 Copilot 助手的三栏协同布局
- 支持中英文界面切换
- 支持对报告产物进行 `html / pdf / text / docx` 等形式的预览与联动展示

### 15.6 可直接填写的接口/模块说明

- 路径诊断接口：用于接收结构化问答并返回诊断结论与报告路径

### 15.7 数据与文件流转方式

- 用户在前端填写结构化表单或上传文档

- 后端解析输入内容，结合规则、知识检索与模型能力生成结构化结果
- 结果以数据库记录与输出文件形式沉淀到本地目录
- 前端在统一工作区中展示报告正文、问题列表、证据命中与输出文件预览
