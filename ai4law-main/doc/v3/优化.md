下面是一份**可落地的改进建议**（按优先级，含改动点）：

**P0 立刻修（影响最大）**

**P1 快速提升质量（1-2天内可做）**
4. **RAG 查询改写（CN 优化）**  
- 做法：在 `backend/common/rag/retriever.py` 前加 query rewrite：中文关键词 + 明确法规名。

- 预期：CN 命中率提升，降低编造。

5. **引用链输出（每段至少1条）**

- 改动点：`doc/knowledge/normalized/regulation_articles.jsonl` 与 ingestion 脚本。

8. **证据覆盖率指标**  
- 做法：统计报告内“有引用的段落比例”，低于阈值输出“证据不足”。
