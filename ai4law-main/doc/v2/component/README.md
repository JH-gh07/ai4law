# AI4Law v2 组件化模块文档

本目录用于沉淀每个模块的可执行规范，统一包含：
- 知识库要求（法规主信源、补充信源、模板资产）
- 输入规范（结构化字段 + 附件要求）
- 输出规范（文件、格式、命名、前端呈现）
- 功能流程（步骤化）
- 验收标准（可测试）

字段同步基线：
- 输入字段优先以 `doc/v2/schemas/raw/module_input_fields.csv` 为准。
- 输出章节映射优先以 `doc/v2/schemas/raw/module_output_structure.csv` 为准。

## 统一约束
- 命名规则：`[企业简称]_[文档类型]_[状态可选]_[YYYYMMDD].扩展名`
- 主输出格式：`docx`（必要时补 `pdf`）
- 多文件交付：`zip`
- 引用要求：报告区分“法规原文依据”与“实务解释依据”
