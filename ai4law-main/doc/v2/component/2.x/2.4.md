# 2.4 通用服务

## 模块目标
提供多种通用合规文书能力：尽调报告、合规备忘录、TIA、整改建议清单。

## 知识库要求

### 法规主信源
- 中国数据出境三路径相关法规
- GDPR Chapter V / SCC / BCR / TIA 指南（跨法域问题）
- CPRA/州法框架（如涉及美国场景）

### 补充信源
- 典型案例与执法通报
- 团队规则包（飞书沉淀）

### 模板资产
- 尽调模板
- 合规备忘录模板
- TIA 模板
- 整改建议清单模板

## 输入规范

### 结构化字段
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| service_type | enum(due_diligence/memo/tia/remediation) | 是 | 服务类型 |
| business_context | string | 是 | 业务背景 |
| jurisdiction | enum(cn/eu/us/mixed) | 是 | 法域 |
| key_questions | string[] | 是 | 关注问题 |
| risk_preference | enum(conservative/balanced/aggressive) | 否 | 风险偏好 |

### 附件清单
| 附件 | 格式 | 必填 | 说明 |
|---|---|---|---|
| 合同/制度/流程文档 | docx/pdf | 否 | 证据材料 |
| 数据清单 | xlsx/csv | 否 | 数据范围支持 |

## 输出规范

### 文件输出
| service_type | 输出文件 | 格式 |
|---|---|---|
| due_diligence | 尽调报告 | docx/pdf |
| memo | 合规备忘录 | docx/pdf |
| tia | TIA 草案 | docx |
| remediation | 风险与整改建议清单 | docx/xlsx |

### 命名
- `[企业简称]_[服务类型]_[日期].扩展名`

### 前端呈现
- 服务类型卡片
- 结论摘要 + 关键建议
- 下载按钮

## 功能流程
1. 选择服务类型。
2. 输入问题与背景，上传材料。
3. 路由知识库与模板。
4. 生成对应文书。

## 落地任务
- 后端：服务路由器 + 多模板渲染。
- 前端：服务切换 UI。
- 数据：不同服务的字段与模板映射。
- 测试：四类服务各 1 套回归样例。

## 验收标准
- 每种 service_type 都有可下载产物。
- 输出内容与所选服务类型一致，不串型。
