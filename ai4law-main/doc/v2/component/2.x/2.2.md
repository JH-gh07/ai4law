# 2.2 安全评估路径

## 模块目标
将企业材料转为《数据出境风险自评估报告（草案）》并支持预览与打包下载。

## 知识库要求

### 法规主信源
- 《数据出境安全评估办法》
- 《数据出境安全评估申报指南（第三版）》
- 《个人信息保护法》《数据安全法》《网络安全法》

### 补充信源
- 省级网信办实务口径（用于材料准备提示）

### 模板资产
- `数据出境风险自评估报告（模板）.docx`
- 申报材料清单模板（附件清单）

## 输入规范

字段来源：`doc/v2/schemas/raw/module_input_fields.csv`（`module=2.2`，来源图 `2.2.1.png`）

## 输出规范

### 文件输出
| 文件 | 命名规则 | 格式 | 必出 |
|---|---|---|---|
| 风险自评估报告草案 | `[企业简称]_数据出境风险自评估报告_草案_[日期].docx` | docx | 是 |
| 输出包 | `[企业简称]_安全评估路径输出包_[日期].zip` | zip | 是 |

### 前端呈现
- 章节在线预览（逐章）
- 引用来源卡片
- 一键下载（docx + zip）

## 功能流程
1. 收集表单 + 上传附件。
2. 抽取企业画像与场景特征。
3. 检索法规依据并生成章节草案。
4. 做一致性校验（阈值、主体、附件齐备性）。
5. 渲染 docx 报告并打包。

## 落地任务
- 后端：材料解析、章节生成、一致性检查、打包。
- 前端：多步表单、上传器、预览与下载。
- 数据：指南条款映射、模板占位字段定义。
- 测试：缺附件、异常文件、超时任务、重试机制。

## 验收标准
- 输入完整时，必产出 docx 与 zip。
- 报告结构与官方模板一致。
- 章节预览与下载结果一致。
