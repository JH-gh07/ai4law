# 2.5 文档专项智能审查（双模式）

## 模块目标
从“单一审查报告”升级为“双模式工作台”：
- 模式A：文本分析 / 审查报告版
- 模式B：合同审查 / 批注修订版

## 对标样本（验收基准）
- `doc/5.通用合同审查使用记录/测试使用的同一个合同.docx`
- `doc/5.通用合同审查使用记录/文本分析功能输出的结果（审查报告docx.docx`
- `doc/5.通用合同审查使用记录/合同审查功能输出的结果（批注修订版.docx`
- `doc/5.通用合同审查使用记录/得理AI 双功能使用差异总结.docx`

## 知识库要求

### 法规主信源
- 《个人信息保护法》
- 《个人信息出境标准合同办法》
- 《数据出境安全评估办法》
- 《网络数据安全管理条例》
- GB/T 35273 等安全规范

### 补充信源
- 典型司法/执法案例
- 行业实务解读
- 自定义规则包（甲方/乙方视角）

### 模板资产
- 审查报告模板（模式A）
- 修订策略模板（模式B）
- 差异输出模板（原文/修订后/理由）

## 输入规范

### 结构化字段
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| review_mode | enum(REPORT/REDLINE) | 是 | 输出模式 |
| contract_type | enum(general/scc/dpa/privacy_policy) | 是 | 合同类型 |
| review_stance | enum(party_a/party_b) | 是 | 审查立场 |
| custom_rule_ids | string[] | 否 | 预设规则包 |
| custom_rule_text | string | 否 | 自定义规则文本 |

### 附件清单
| 附件 | 格式 | 必填 | 说明 |
|---|---|---|---|
| 待审主合同 | docx/pdf | 是 | 核心输入 |
| 附录/补充协议 | docx/pdf | 否 | 附件覆盖 |
| 隐私政策/内部制度 | docx/pdf | 否 | 一致性比对 |

## 输出规范

### 模式A（REPORT）
| 文件 | 命名规则 | 格式 | 说明 |
|---|---|---|---|
| 数据出境合同合规审查报告 | `[企业简称]_合同审查报告_[日期].docx` | docx | 标准化问题清单 |
| 结构化问题清单 | `[企业简称]_合同审查问题_[日期].json` | json | 前端结构化展示 |

### 模式B（REDLINE）
| 文件 | 命名规则 | 格式 | 说明 |
|---|---|---|---|
| 修订版合同 | `[企业简称]_修订版合同_[日期].docx` | docx | 完整合同（正文+附录） |
| 差异清单 | `[企业简称]_修订差异_[日期].json` | json | 原文/修订后/理由 |
| 批注版（增强） | `[企业简称]_批注修订版_[日期].docx` | docx | Word 批注痕迹 |

### 前端呈现
- 输入区：合同类型、立场、规则、模式切换
- 结果区：
  - 模式A：报告预览 + 问题列表
  - 模式B：修订合同下载 + 差异视图

## 功能流程
1. 文件解析（正文/附录/表格）。
2. 条款切分与分类。
3. 法规/规则检索。
4. 问题识别（共享）。
5. 分支：
- 模式A：聚合风险 -> 生成报告。
- 模式B：修订策略 -> 条款改写 -> 合同重组 -> 差异输出。

## 落地任务
- 后端：Review Orchestrator（共享链路 + 双分支）。
- 前端：双模式工作台与差异展示。
- 数据：规则包、合同类型词典、条款分类标签。
- 测试：同一合同双模式回归、立场差异回归、附录覆盖测试。

## 验收标准
- 模式A稳定产出标准审查报告。
- 模式B产出完整修订合同，且差异可追溯。
- 同一合同在甲/乙视角下，问题排序或建议存在差异。
