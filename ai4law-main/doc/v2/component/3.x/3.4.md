# 3.4 TIA草案生成

## 模块目标
生成欧盟跨境传输 TIA 草案，用于传输工具合规论证。

## 知识库要求

### 法规主信源
- EDPB Recommendations 01/2020
- EDPB Recommendations 02/2020
- EDPB 第三国政府访问研究报告

### 补充信源
- TIA 实务指引（机构发布）

### 模板资产
- `TIA - Template.docx`

## 输出规范
| 文件 | 命名规则 | 格式 |
|---|---|---|
| TIA 草案 | `[企业简称]_TIA_草案_[日期].docx` | docx |

## 功能流程
1. 按 `3.4-1.1~3.4-6.1` 收集并校验字段。
2. 检索法规与目的地法律实践依据。
3. 生成 TIA 章节并输出。

## 验收标准
- 包含国家风险评估与补充措施章节。
- 结论与依据可追溯。
