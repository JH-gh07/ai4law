# “合规路径诊断”功能说明与路径描述（标注Reference）

“合规路径诊断”功能说明与路径描述（标注Reference）
“合规路径诊断”功能说明：
用户无需自行解读法规，仅需通过网页表单回答一系列预设的、具有明确选项的封闭式问题。输入信息本质上是关于其数据出境业务场景的关键事实，包括：
	•	拟出境数据是否包含“重要数据”。
	•	拟出境数据是否包含“个人信息”。
	•	如包含个人信息，是否属于法定的豁免情形。
	•	数据处理者是否为“关键信息基础设施运营者”。
	•	自当年1月1日起累计拟出境的个人信息类型（一般个人信息或敏感个人信息）及数量规模。
“合规路径诊断”路径描述：
1.用户输入 
用户通过网页表单回答一系列预设的、具有明确选项的封闭式问题。输入信息本质上是关于其数据出境业务场景的关键事实。系统设计需考虑用户可能对某些事实不确定（回答“不知道”），此时需引导用户提供更详细的描述性信息以供进一步分析。
2.诊断步骤与规则引擎逻辑
系统诊断流程严格按照预设的决策树顺序执行，每一步的判断都基于特定法律条款。当用户回答“不知道”时，系统将启动次级信息收集与判断流程。
步骤一：识别“重要数据”出境义务
	•	用户输入：回答“本次向境外提供的数据中，是否包含被相关部门或您所在行业认定为‘重要数据’的数据？” 选项为：是、否、不知道。
	•	系统诊断逻辑：
	•	选择“是”：系统立即终止主流程，跳转至最终结论输出（必须申报安全评估）。
	•	选择“否”：系统进入步骤二。
	•	选择“不知道”：系统启动重要数据辅助判断子流程：
	•	询问行业领域：“请选择您企业所属的主要行业或领域（例如：工业、电信、交通、金融、自然资源、卫生健康、教育、科技、能源、国防科工、文旅、跨境电商、零售、互联网等）。”【 依据：《数据安全法》第二十一条要求各地区、各部门确定本行业、本领域的重要数据具体目录。】
	•	询问数据性质：“请描述拟出境数据的具体内容与用途。例如：是否涉及国家经济运行、社会稳定、公共安全、生态环境、科技安全等宏观层面的数据？是否包含未公开的政务数据、工作秘密？是否包含达到一定精度和规模的群体性、区域性、系统性基础数据（如地图、自然资源、基因等）？” 【依据：参考国家网信办及各行业主管部门（如工信、金融、卫健、交通等）发布的重要数据识别指南或相关标准（如《信息安全技术 重要数据识别指南》（征求意见稿）、《金融数据安全 数据安全分级指南》（JR/T 0197-2020）等）中关于重要数据特征的描述。】
	•	判断与反馈：系统根据用户输入的行业和数据性质描述，结合内置的行业重要数据特征库进行匹配分析。若匹配到高风险特征，则提示“根据您提供的信息，该数据可能涉及重要数据，建议您咨询行业主管部门或专业机构进行最终确认。基于审慎原则，系统建议按涉及重要数据处理。”并引导用户回到主问题重新选择“是”。若未匹配到明显特征，则提示“根据现有信息，初步判断不涉及典型的重要数据。但最终认定需以主管部门目录为准。”并引导用户选择“否”进入下一步。
	•	该步骤整体的依据：
	•	《促进和规范数据跨境流动规定》第七条：“数据处理者向境外提供重要数据，应当申报数据出境安全评估。”
	•	《中华人民共和国数据安全法》第二十一条：“国家建立数据分类分级保护制度…各地区、各部门应当按照数据分类分级要求，确定本地区、本部门以及相关行业、领域的重要数据具体目录，对列入目录的数据进行重点保护。” 以及各行业主管部门发布的相关重要数据识别指南或标准。
步骤二：识别“个人信息”与基础豁免
	•	用户输入：回答“本次向境外提供的数据中，是否包含‘个人信息’？” 选项为：是、否、不知道。
	•	系统诊断逻辑：
	•	选择“否”：系统立即终止主流程，跳转至最终结论输出（适用《规定》第三条豁免）。
	•	选择“是”：系统进入步骤三。
	•	选择“不知道”：系统启动个人信息辅助判断子流程：
	•	提供示例清单：“请核对，拟出境数据中是否包含以下任何一类信息：自然人的姓名、出生日期、身份证件号码、生物识别信息、住址、电话号码、电子邮箱、账号密码、财产信息、行踪轨迹、健康生理信息、交易信息等？” 【依据：《中华人民共和国个人信息保护法》第四条对个人信息的定义，以及第二十八条对敏感个人信息的列举。】
	•	判断与反馈：若用户确认包含清单中任何信息，则提示“根据您的描述，该数据包含个人信息。”并引导用户回到主问题选择“是”。若用户确认不包含任何清单信息，则提示“根据您的描述，该数据不包含个人信息。”并引导用户选择“否”。
	•	该步骤整体依据：
	•	核心判断依据：《促进和规范数据跨境流动规定》第三条：“…不包含个人信息或者重要数据的，不需要申报数据出境安全评估、订立个人信息出境标准合同、通过个人信息保护认证。”
	•	概念依据：《中华人民共和国个人信息保护法》第四条：“个人信息是以电子或者其他方式记录的与已识别或者可识别的自然人有关的各种信息，不包括匿名化处理后的信息。”
步骤三：核查法定豁免情形
	•	用户输入：回答“请判断本次个人信息出境是否属于以下任一法定豁免情形？”（可多选，选项对应《规定》具体条款）。同时提供“不清楚/不确定”选项。
	•	系统诊断逻辑：
	•	用户选择任一具体豁免情形：系统立即终止主流程，跳转至最终结论输出（适用对应豁免）。
	•	用户选择“均不属于”：系统进入步骤四。
	•	用户选择“不清楚/不确定”：系统启动豁免情形辅助判断子流程，针对《规定》第五条、第六条列举的每一项豁免情形进行细化询问：
	•	针对《规定》第五条第一项（履行合同必需）：“本次数据出境是否是为了履行您与个人用户之间已签订的合同（例如：为完成其发起的跨境购物、支付、寄递、开户、预订、签证、考试等服务）？且该数据出境是否为履行该合同所‘必需’（即不出境则合同无法履行）？” 【依据：《促进和规范数据跨境流动规定》第五条。】
	•	针对《规定》第五条第二项（紧急情况）：“本次数据出境是否是为了应对保护自然人生命健康和财产安全的紧急情况（例如：跨境医疗救助、灾害救援）？” 【依据：《促进和规范数据跨境流动规定》第五条。】
	•	针对《规定》第六条（跨境人力资源管理）：“本次数据出境是否仅涉及员工个人信息，且是基于依法制定的劳动规章制度或依法签订的集体合同，为实施跨境人力资源管理（如薪酬发放、福利管理、派遣安排）所必需？”【 依据：《促进和规范数据跨境流动规定》第六条。】
	•	针对《规定》第五条第三项（少量个人信息）：此情形与后续数量判断合并，在本步骤不单独询问。
	•	针对《规定》第六条（自贸区负面清单）：“本次数据出境活动是否发生在自由贸易试验区，且不属于该试验区负面清单禁止的范围？” 【依据：《促进和规范数据跨境流动规定》第六条及各自贸试验区发布的负面清单。】
	•	判断与反馈：根据用户对上述细化问题的回答，系统判断是否符合任一豁免情形。若符合，则引导用户回到主问题选择对应豁免项；若均不符合，则引导用户选择“均不属于”。
	•	该步骤整体依据：
	•	《促进和规范数据跨境流动规定》第三条、第五条、第六条。
步骤四：确认数据处理者身份（是否CIIO）
	•	用户输入：回答“您的企业是否属于‘关键信息基础设施运营者’？” 选项为：是、否、不确定。
	•	系统诊断逻辑：
	•	选择“是”：系统立即终止主流程，跳转至最终结论输出（必须申报安全评估）。
	•	选择“否”：系统进入步骤五。
	•	选择“不确定”：系统启动CIIO辅助判断子流程：
	•	询问行业属性：“您的企业是否属于以下重要行业和领域：公共通信和信息服务、能源、交通、水利、金融、公共服务、电子政务、国防科工等？” 【依据：《中华人民共和国网络安全法》第三十三条。】
	•	询问官方通知：“您是否曾收到国家网信部门或行业主管监管部门的通知，被正式认定为关键信息基础设施运营者？” 【依据：《关键信息基础设施安全保护条例》相关规定。】
	•	判断与反馈：若用户确认属于重要行业且/或收到过认定通知，则提示“您很可能属于关键信息基础设施运营者，建议向主管部门确认。基于合规审慎原则，系统建议按CIIO处理。”并引导用户选择“是”。若用户确认不属于重要行业且未收到通知，则提示“根据现有信息，初步判断不属于CIIO。”并引导用户选择“否”。
	•	该步骤整体依据：
	•	核心判断依据：《促进和规范数据跨境流动规定》第七条：“关键信息基础设施运营者向境外提供个人信息或者重要数据，应当申报数据出境安全评估。”
	•	概念依据：《中华人民共和国网络安全法》第三十三条：“国家对公共通信和信息服务、能源、交通、水利、金融、公共服务、电子政务等重要行业和领域，以及其他一旦遭到破坏、丧失功能或者数据泄露，可能严重危害国家安全、国计民生、公共利益的关键信息基础设施，在网络安全等级保护制度的基础上，实行重点保护。关键信息基础设施的具体范围和安全保护办法由国务院制定。”
步骤五：区分与量化个人信息类型
此步骤开始进行核心的量化判断路径。
	•	用户输入：首先回答“自今年1月1日起，您累计向境外提供的个人信息，主要涉及哪种类型？” 选项为：A. 仅涉及一般个人信息；B. 涉及敏感个人信息；C. 不确定。
	•	系统诊断逻辑：
	•	选择A或B：进入相应的量化子步骤。
	•	选择C（不确定）：系统启动个人信息类型辅助判断子流程：
	•	提供敏感个人信息清单：“请核对，拟出境信息中是否包含以下任何一类：生物识别信息（如人脸、指纹）、宗教信仰、特定身份（如犯罪记录）、医疗健康、金融账户、行踪轨迹信息，或不满十四周岁未成年人的个人信息？” 【依据：《中华人民共和国个人信息保护法》第二十八条。】
	•	判断与反馈：若用户确认包含清单中任何信息，则提示“根据您的描述，涉及敏感个人信息。”并引导用户选择B。若用户确认不包含，则提示“根据您的描述，仅涉及一般个人信息。”并引导用户选择A。
步骤五（A）子路径：量化一般个人信息
	•	用户输入：选择A后，回答“请估算，自今年1月1日起，您累计向境外提供的一般个人信息总人数约为？” 选项为：不足10万人；10万人以上，但未达到100万人；100万人以上；无法估算。
	•	系统诊断逻辑：
	•	选择具体数量区间：根据选择输出对应结论（豁免/标准合同或认证/安全评估）。
	•	选择“无法估算”：系统提供指导：“请根据您的业务规模、用户基数、出境频率进行估算。例如：日均/月均出境人数 × 天数/月数。若确实无法估算，建议进行数据盘点。基于合规审慎原则，若无法排除超过100万人的可能性，建议按最高合规要求（安全评估）准备。”并引导用户尽可能选择一个区间。
	•	该步骤整体依据：
	•	《促进和规范数据跨境流动规定》第五条（豁免）、第八条（标准合同/认证）、第七条（安全评估）。
步骤五（B）子路径：量化敏感个人信息
	•	用户输入：选择B后，回答“请估算，自今年1月1日起，您累计向境外提供的敏感个人信息总人数约为？” 选项为：不足1万人；1万人以上；无法估算。
	•	系统诊断逻辑：
	•	选择具体数量区间：根据选择输出对应结论（标准合同或认证/安全评估）。
	•	选择“无法估算”：系统提供指导：“请根据涉及敏感个人信息的业务场景（如人脸识别登录、跨境医疗、跨境金融等）的用户规模进行估算。基于合规审慎原则，若无法排除超过1万人的可能性，建议按最高合规要求（安全评估）准备。”并引导用户尽可能选择一个区间。
	•	该步骤整体依据：
	•	《促进和规范数据跨境流动规定》第八条（标准合同/认证）、第七条（安全评估）。
	•	概念依据：《中华人民共和国个人信息保护法》第二十八条。
三、 系统输出 
诊断流程终止后，系统生成并交付文件《合规路径诊断报告》，具有以下内容：
	•	核心结论：以上述逻辑推导出的最终合规路径。
	•	结构化诊断报告：包括用户答案摘要、判定逻辑树、逐条法规依据、核心风险提示、后续行动建议。
