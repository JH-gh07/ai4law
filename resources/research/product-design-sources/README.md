# 产品设计来源材料

本目录保存早期《整体统筹开发文档》拆分出的设计素材、输入清单截图和外部模板来源。它用于解释产品设计来源，不是生产法规、正式模板或当前功能实现的事实依据。

- `00_index/`：来源目录、命名规则和原始统筹文档；
- `01_pathway_layer/`：中国、美国及待研究欧洲路径层设计来源；
- `02_function_layer/`：合同审查、表单和报告生成模块的设计来源。

已进入 `resources/legal/` 或 `resources/templates/` 的同 Hash 文件不再保留研究副本，规范位置记录在来源索引中。其余截图和原始统筹材料仅用于来源追溯，引用前必须确认来源、许可、版本和人工改造范围。
