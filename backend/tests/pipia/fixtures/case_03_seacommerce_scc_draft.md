# 个人信息出境标准合同草案（脱敏测试夹具）

> 文件性质：本文件根据“认证/标准合同路径”测试案例一派生，仅用于本地自动化验收；不是案例原文附件，不是正式签署文本，也不能作为真实备案材料。

## 一、合同主体与出境场景

- 个人信息处理者：海淘优选（杭州）科技有限公司。
- 境外接收方：SeaCommerce Pte. Ltd.，所在地为新加坡。
- 出境目的：个性化营销与市场分析。
- 涉及主体：约 50 万名高价值会员。
- 数据类别：偏好标签、浏览记录（哈希设备 ID）和订单摘要。
- 处理方式：由中国大陆系统定期向新加坡接收方传输，由接收方完成会员分析。

## 二、当前法律基础与主体权利安排

- 当前主张的法律基础为单独同意，并同时提出合同履行必要性。
- 已提供单独同意界面截图，但尚未提供覆盖全部 50 万名会员的批量同意日志。
- 当前隐私政策只概括提及“关联方”，没有明确列出 SeaCommerce Pte. Ltd. 及其联系方式。
- 数据主体权利请求渠道、境外接收方响应时限和跨境投诉转交机制尚待补充。

## 三、数据分类与安全措施

- 浏览记录使用哈希设备 ID，但尚未提供哈希算法、碰撞风险和重新识别风险评估。
- 偏好标签可能推断健康或孕产状态，现有材料仍将其统一标为非敏感信息，需重新分类。
- 接收方声明遵守新加坡 PDPA，但尚未提供独立审计、认证或持续监督材料。
- 当前隐私政策版本为 2023 年，尚未完成本次业务上线前更新。

## 四、草案已知缺口

1. 尚未写明新加坡法律或监管政策变化时的通知、评估和暂停传输机制。
2. 尚未约定境外接收方定期提交审计报告和整改证明。
3. 尚未完成敏感个人信息重新分类、单独同意留痕和数据最小化复核。
4. 尚未补齐接收方保护能力证明、数据保留期限和合同终止后的删除或返还安排。

## 五、测试验收边界

本草案只证明系统能够读取一个与源案例事实一致、且明确保留缺口的本地附件。上述缺口未整改前，不应把本文件解释为“可以直接备案”或“已满足全部标准合同要求”。
