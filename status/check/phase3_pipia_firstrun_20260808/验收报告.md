## 7. 浏览器端到端验收

浏览器用例不是直接调用 service，而是依次执行：注册 → 创建 PIPIA 任务 → 填表 → 选择本地文件 → `/files/upload` → `/pipia/generate_async` → 轮询任务 → 打开报告 → 打开引用抽屉 → 跳转知识库。

## 10. 保留限制，不掩盖

| 限制 | 影响 | 当前处理 |
|---|---|---|
| 成功 live run 早于“截断 marker 清理”补丁 | 该次已归档 Markdown 第 117、139 行仍有两段不完整 marker | 后续代码已有确定性回归；没有为此再次消耗 7 次真实 provider 调用 |
| ZIP 不包含 `citation_map.json` | 用户下载包内无法直接查看 CitationMap | 当前输出接口仍单独返回 CitationMap；是否加入 ZIP 需作为跨模块统一产物契约处理 |
| 真实 provider 用时约 392 秒 | 本地真实生成仍慢 | token 已下降约 48%，但 provider 延迟仍需后续性能治理 |

这三项不阻断“PIPIA 本地功能闭环通过”，但阻断“PIPIA 已达到最终生产完成”的说法。
