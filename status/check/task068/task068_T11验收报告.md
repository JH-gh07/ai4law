## 3. shadow 原语（本次新增）

`backend/common/reporting/shadow_render.py` 提供 module-agnostic 的：

- `render_ir_artifacts(document_ir, registry, output_dir, module, task_id)` — 包装 `build_render_manifest`，把 MD/DOCX/PDF/IR/citation_map/manifest 写入隔离目录；
- `audit_ir_vs_legacy(manifest, legacy_finding_ids, ...)` — 只比较并记录 finding/section/citation 身份差异，**从不改写法律结论**；`pdf_font_gate` 恒为 `blocked`（未嵌入 CJK 字体，不伪造 pass）；
- `write_audit_json(audit, path)` — 写审计，不含 token/secret/正文。

`backend/domains/eu/bcr_review/shadow_render.py` 改为 backward-compatible re-export，BCR 既有 7 个 shadow/switch/rollback 测试全绿（含 stage A shadow、stage B switch、switch 需 schema-first、rollback flag off 恢复 legacy 且不删 IR artifact）。

新增 `backend/common/reporting/tests/test_shadow_render.py`（3 passed）证明原语对 cpra/eo14117/dpia/review 四模块名都可复用，且审计不含敏感正文。

## 4. 切换门禁（BLOCKED，未伪造）

T11 的切换条件要求「T00-T10 全部通过、无未解释 P0/P1、字体与 LibreOffice 门禁通过、至少一个真实 HTTP+浏览器闭环通过」。当前：

- **PDF CJK 字体**：`BLOCKED_BY_FONT`（无可再分发 CJK 字体，STSong-Light emb=no）→ shadow 审计中 `pdf_font_gate` 如实 `blocked`；
- **DOCX 视觉**：`BLOCKED_BY_TOOLING`（LibreOffice/soffice 缺失）；
- **浏览器矩阵**：无远程部署、无真实浏览器二进制运行条件。

因此本阶段**不执行真实切换**，也不删除任何旧 writer。结论：切换与「退出旧路径」推迟到上述三项门禁通过后。

## 5. 回滚演练（真实命令与输出）

BCR 已用 two-flag 完整演练（既有 `test_shadow_render.py`）：

```text
$ uv run --frozen pytest backend/domains/eu/bcr_review/tests/test_shadow_render.py -q

$ uv run --frozen pytest backend/common/reporting/tests/test_shadow_render.py -q

$ uv run --frozen ruff check backend/common/reporting/ backend/domains/eu/bcr_review/shadow_render.py backend/core/settings.py
All checks passed!
```

rollback 语义（`test_rollback_flag_off_restores_legacy_and_keeps_ir_artifacts`）：
1. flag on → 官方输出为 IR + manifest；
2. flag off → legacy 重新成为官方输出，**先前生成的 IR/manifest 文件不被删除**；
3. 回滚后的任务仍 shadow 渲染 IR 供比对（`shadow_ir/render_manifest.json` + `render_audit.json` 存在）。

垂直模块 CPRA/EO/DPIA 的 rollback 由既有 schema-first 测试覆盖 flag on/off 两分支（DPIA `schema_first_enabled=True/False` 双路径、CPRA `schema_first_enabled=True` 产出 IR 官方 + `document_ir_json`）。
