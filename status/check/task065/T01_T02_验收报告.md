## T02：修复 Seed Level A，建立来源保真抽取

### 2.1 根因与修复

根因：`scripts/build_seed_case_inputs.py` 使用旧文件名 glob `任务*_案例*_测试结果.docx`，而迁移后规范文件名为 `taskNN_caseM.docx`，glob 命中 0。

修复（重写脚本）：

1. **manifest 是唯一输入清单**：`load_manifest_entries()` 从 `manifest.json` 的 `tasks -> files` 读取 50 条，不再 glob；
2. **强一致性门禁**：`verify_disk_vs_manifest()` 校验条目数==50、路径存在、task/case 与文件名解析一致、SHA-256 一致、size 一致；缺文件/多文件/改名/改 Hash/改 size 均 `SystemExit(2)`；
3. **规范文件名解析**：`parse_canonical_name("taskNN_caseM.docx")` 仅用于交叉校验，manifest 仍是权威；
4. **Gold 原件豁免**：Gold 原件 `数规通黄金标准_v1.0.docx` 是 50 个 case 之外的独立清单项，不计入 case-file 集合；
5. **只写 inputs**：`--write` 只写 `inputs/`，不再创建 `expected/`（已删除旧代码中的 `exp_dir` 写入和 `.gitkeep`）。
