## 2. 演示主线与MVP路径

### 2.1 核心演示场景

确定1-2个最能体现系统价值的演示场景。建议选择**中国数据出境合规路径诊断 + 安全评估报告生成**的完整链路（路径诊断→进入对应模块→生成报告→查看依据→完成闭环）。

### 2.2 端到端演示路径

```text
首页（30秒：快速说明平台定位）
  → 任务空间（30秒：选择CN中国任务包）
  → 合规路径诊断（1分钟：填写场景数据→查看路径结论和依据）
  → 安全评估模块（1.5分钟：填写企业信息→触发AI生成→查看报告）
  → 报告引用追溯（30秒：点击引用角标→查看法规原文→回到报告）
  → 产物下载与查看（30秒：预览PDF→下载）
  → 知识库中心（30秒：检索法规→查看条文）
```

### 2.3 演示关键节点

| 节点 | 展示重点 | 讲稿要点 |
|---|---|---|
| 首页 | 平台定位 | "我们的平台解决数据跨境合规的全流程问题" |
| 路径诊断 | 规则引擎 | "不是直接问AI，而是代码规则先做确定性判断" |
| 报告生成 | RAG+LLM协作 | "AI生成的内容每条都有法规依据" |
| 引用追溯 | 可解释性 | "每个结论都能追溯到具体法律条文" |
| 产物输出 | 工程完整性 | "输出专业级别的报告文档" |

## 4. 演示脚本

### 4.1 开场（{1-2分钟}）

讲稿要点：
- 我们做的是DataComplyFlow数规通平台
- 解决企业数据跨境合规的三大痛点：路径不清、依据不足、文书难写
- 核心创新：规则引擎+大模型+工作流编排，不是简单套壳AI

### 4.2 主流程演示（{4-5分钟}）

按2.2节的路径，逐节点配讲稿。

### 4.3 AI亮点展示（{2-3分钟}）

三个必展AI亮点：
1. **依据可追溯**：报告里的每条结论都能点开看法律原文
2. **规则与AI互补**：确定性判断交给代码，生成表达交给大模型
3. **评测有据**：展示评测数据和Token花费，证明AI不是盲目调用

### 4.4 总结收尾（{1分钟}）

- 一句话总结：**不是AI能回答问题，而是能把一项合规任务完整做下来**
