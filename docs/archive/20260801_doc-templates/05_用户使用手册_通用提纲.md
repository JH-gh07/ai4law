### 4.1 合规路径诊断

**模块简介**：帮您判断数据出境应该走什么合规路径。

**适用场景**：不确定是豁免、标准合同/认证、还是需要申报安全评估。

**操作步骤**：
1. 在任务空间选择"合规路径诊断"
2. 填写企业类型、数据类别、数据量级、接收方信息等
3. 点击"开始诊断"
4. 查看路径结论：豁免 / 标准合同/认证 / 安全评估
5. 查看关键依据和后续动作建议

**输出说明**：
- 路径结论：系统判断的推荐路径
- 命中规则：触发了哪些法律规则
- 法规依据：每条结论引用的法规条文
- 缺失信息：如需更准确判断，系统会提示还需补充什么
