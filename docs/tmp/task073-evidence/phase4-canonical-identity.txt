=== 设计要点 ===
- registry_source_id 是 additive 字段，所有 CitationItem 构造均为 keyword 参数，无 positional 破坏。
- SourceIdentityResolver 只做 exact membership（dict lookup），不做 fuzzy 提升；
  DeliLegal/fallback 合成 source_id 未注册即 UNREGISTERED。
- INELIGIBLE 触发条件：review_status == metadata_review_required 或 can_be_cited == False。
- fail-closed 输出：can_enter_external_report=False、external_report_allowed=False、
  allowed_usage=["internal_review"]；registry_source_id 记录权威 id（UNREGISTERED 为 None）。
- build_citations 未传 resolver 时 registry_source_id 保持 None，行为与基线一致（公共链无变化）。

=== 三类 fixture ===
- registered：CN-LAW-002-001 命中 → REGISTERED，registry_source_id 正确，读取权威 policy ✓
- unregistered：delilegal-law-* 未命中 → UNREGISTERED，registry_source_id=None，fail-closed ✓
- ineligible：review_status=metadata_review_required / can_be_cited=False → INELIGIBLE ✓
- 无 fuzzy 提升：近似 source_id 不命中 → UNREGISTERED ✓

=== 重复 citation 关系 union ===
- 低置信度重复项（0.7 < 0.9）仍 union 三类关系：issue/fact/evidence 集合合并，最高置信度保留 ✓
